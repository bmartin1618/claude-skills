# Form 1065 Review Workflow

## Step 1: Entity Information Verification

### 1.1 Partnership Identification
**Procedure:**
1. Locate partnership name on Page 1, top section
2. Verify EIN present and properly formatted (XX-XXXXXXX)
3. Check business address - note if P.O. Box (may require physical address for some states)
4. If prior year return available, verify name and EIN match exactly

**What to Flag:**
- EIN mismatch with prior year
- Name change without Form 8822-B filed
- Address change crossing state lines (nexus implications)

**Pass Criteria:** Name, EIN, and address present and consistent
**Fail Criteria:** Missing EIN, mismatches with K-1s or prior year

### 1.2 Principal Business Activity Code
**Procedure:**
1. Locate 6-digit NAICS code on Page 1
2. Verify code matches actual business activity
3. Compare to prior year - if changed, determine if appropriate

**Common Codes:**
- 531110: Lessors of residential buildings
- 531120: Lessors of nonresidential buildings
- 541211: CPA firms
- 531210: Real estate agents

**Pass Criteria:** NAICS code accurately describes business
**Fail Criteria:** Generic code (e.g., 999999) or mismatch with actual business

### 1.3 Accounting Method Verification
**Procedure:**
1. Locate accounting method checkbox on Page 1:
   - Cash
   - Accrual
   - Other (specify)
2. Compare to prior year - method should be consistent
3. If changed, verify Form 3115 (change in accounting method) was filed

**Revenue Recognition Test:**
```
Does partnership have inventory or gross receipts > $27M (2024)?
├─ YES → Accrual method generally required
│   └─ Verify partnership uses accrual
└─ NO → Cash method permitted
    └─ Verify method consistent with books
```

**Pass Criteria:** Appropriate method selected, consistent year-over-year
**Fail Criteria:** Method changed without Form 3115, inappropriate for business type

### 1.4 Partner Count Reconciliation
**Procedure:**
1. Count number of Schedule K-1s attached to return
2. Compare to "Number of Schedules K-1" shown on Page 1
3. Verify all K-1s present (if return package incomplete, note missing K-1s)

**Technical Termination Check (§708):**
```
Did >50% of partnership interests transfer within 12 months?
├─ YES → Technical termination occurred
│   ├─ Partnership deemed terminated and reformed
│   ├─ Short tax year created
│   ├─ New EIN may be required
│   ├─ Assets/liabilities treated as distributed then contributed
│   └─ THIS IS MAJOR EVENT - Document if occurred
└─ NO → Normal continuation of partnership
```

**Pass Criteria:** K-1 count matches, all K-1s present
**Fail Criteria:** Mismatch in count, missing K-1s, technical termination not addressed

## Step 2: Book-Tax Reconciliation Review

### 2.1 Schedule M-1 or M-3 Analysis
**Determine Which Schedule:**
```
Total assets (Schedule L) OR gross receipts OR total assets < $10M?
├─ YES → Schedule M-1 required (simple reconciliation)
└─ NO → Schedule M-3 required (detailed reconciliation)
```

### 2.2 Schedule M-1 Review (If Applicable)
**The Critical Reconciliation - Must Balance:**

```
Schedule M-1 Logic Flow:

Line 1: Net income per books (from financial statements)
Lines 2-5: ADD items included in books but not in taxable income
Line 6: ADD items not deducted on books but deducted for tax
Line 7: SUBTOTAL
Line 8: Taxable income (from Form 1065 Analysis, Line 1)
Line 9: DEDUCT items included in taxable income but not on books
Line 10: DEDUCT deductions per tax not charged against books

LINE 7 MUST EQUAL LINE 8 (if reconciliation correct)
```

**Common Book-Tax Differences:**

**INCREASES to book income (Lines 2-5):**
1. **Line 2: Income on books not on return**
   - Tax-exempt interest (municipal bonds)
   - Life insurance proceeds
   
2. **Line 3: Expenses on books not deducted for tax**
   - Meals and entertainment (50% limitation)
   - Federal income taxes (not deductible)
   - Penalties and fines
   - Political contributions
   - Life insurance premiums (if partnership is beneficiary)
   - Charitable contributions (separately stated)
   - §179 expense (separately stated)
   - Non-deductible portion of business gifts (>$25)
   
3. **Line 4: Income on return not on books**
   - Accrued income not yet booked
   - Tax accounting method differences

**DECREASES to taxable income (Lines 5-8):**
1. **Line 5: Deductions on return not on books**
   - Depreciation (tax > book)
   - Special bonus depreciation
   - §179 expense (if more than booked)
   
2. **Line 6-7: Other adjustments**

**Verification Steps:**
1. Obtain partnership's financial statements (P&L)
2. Identify book net income
3. Verify Line 1 matches book net income
4. Review each adjustment for reasonableness
5. Calculate Line 7 total
6. Compare to Line 8 (taxable income from Form 1065 Analysis)
7. Investigate any mismatch

**Common Errors:**
- Meals at 100% instead of 50% disallowance
- Separately stated items not added back
- Depreciation difference calculated incorrectly
- Tax-exempt income not added back

**Pass Criteria:** Schedule M-1 balances, all book-tax differences identified and reasonable
**Fail Criteria:** Does not balance, missing adjustments, unexplained large differences

### 2.3 Schedule L - Balance Sheet Verification

**Balance Sheet Must Balance:**
```
ASSETS (Lines 1-14) = LIABILITIES (Lines 15-20) + CAPITAL (Line 21-22)

Verify:
Line 14 (Total assets) = Line 22 (Total liabilities + capital)
```

**Asset Review:**
1. **Cash (Line 1)** - Ties to bank statements, reasonable ending balance
2. **Accounts Receivable (Lines 2a-2b)** - Check allowance for bad debts
3. **Inventory (Line 3)** - Verify method (FIFO, LIFO, average)
4. **Buildings & Equipment (Lines 10a-10b)** - Check accumulated depreciation
   ```
   Line 10a: Cost
   Line 10b: Less accumulated depreciation
   Net = Line 10c
   
   Accumulated depreciation should increase each year
   ```

**Liability Review:**
1. **Accounts Payable (Line 15)** - Reasonable for business size
2. **Mortgages/Notes Payable (Lines 16-17)** - Verify classification:
   - Line 16: Short-term (due < 1 year)
   - Line 17: Long-term (due ≥ 1 year)
3. **Other Liabilities (Line 19)** - Detail significant items

**Capital Review (Critical!):**
```
Line 21: Partners' capital accounts

MUST tie to Schedule M-2 Line 8 (Ending capital accounts)

This is the #1 place partnerships fail reviews
```

**Year-Over-Year Test:**
```
Prior Year Ending Balance Sheet Assets/Liabilities
SHOULD EQUAL
Current Year Beginning Balance Sheet Assets/Liabilities

If mismatch → Investigate:
- Correction of prior year error?
- Accounting method change?
- Asset/liability reclassification?
Document explanation
```

**Pass Criteria:** Balance sheet balances, ties to prior year, capital ties to M-2
**Fail Criteria:** Does not balance, no tie to prior year, capital ≠ M-2

### 2.4 Schedule M-2 - Partners' Capital Account Analysis
**This Schedule Tracks Partners' Equity - Critical for K-1 Accuracy:**

**The Flow:**
```
Line 1: Beginning capital (must tie to prior year Line 8)
Line 2: Add - Capital contributed during year
Line 3: Add - Net income per books (from Schedule M-1 Line 1)
Lines 4-5: Add - Other increases
Line 6: Less - Distributions to partners
Lines 7-8: Less - Other decreases
Line 8: ENDING CAPITAL (must tie to Schedule L Line 21)
```

**Critical Verification:**
```
Schedule M-2 Line 8 = Schedule L Line 21

If not equal → Major error, cannot file until resolved
```

**Capital Contribution Check:**
```
Line 2: Capital contributed

For each contribution:
1. Identify contributing partner
2. Determine form:
   - Cash contribution (amount = FMV)
   - Property contribution (record FMV, track basis separately for §704(c))
3. Verify contribution date (important for allocation)
4. Update individual partner capital accounts
5. Verify contribution reflected on partner's K-1 Part II, Line 16
```

**Distribution Check:**
```
Line 6: Distributions

For each distribution:
1. Identify receiving partner
2. Determine type:
   - Cash distribution (reduce capital by amount)
   - Property distribution (reduce capital by FMV)
3. Verify distribution date
4. Check if distribution exceeds partner's basis (gain recognition!)
5. Verify reflected on partner's K-1 Part II, Line 19
```

**Capital Account Maintenance Method:**
```
Partnership must choose ONE method (check box on Schedule M-2):

□ Tax Basis - Follows IRC §705 basis rules
  Most common, tracks tax basis

□ GAAP - Book capital accounts
  Follows financial accounting

□ §704(b) - Substantial Economic Effect
  Required for special allocations
  Most detailed tracking

□ Other (specify)

Method must be CONSISTENT for all partners and all years
```

**Pass Criteria:** M-2 reconciles, ties to prior year and Schedule L, method consistent
**Fail Criteria:** M-2 doesn't tie to Schedule L, capital accounts negative without explanation

## Step 3: Income and Deduction Verification

### 3.1 Gross Receipts Analysis (Line 1a)
**Procedure:**
1. Locate Line 1a (gross receipts or sales)
2. Compare to prior year - calculate growth rate
3. Check for Form 1099-K (payment card and third party network transactions)
4. Verify reasonableness for business type

**Growth Rate Analysis:**
```
Growth Rate = (Current Year - Prior Year) ÷ Prior Year × 100%

Expected Range: -10% to +30% typically

If outside range, investigate:
├─ Large growth: New location? Major client? Changed pricing?
├─ Large decline: Lost client? Economic downturn? One-time prior year item?
└─ Exactly same: Suspicious - might be estimated
```

**Pass Criteria:** Gross receipts reasonable, supported by books, ties to revenue accounts
**Fail Criteria:** Unexplained large change, round numbers suggesting estimates

### 3.2 Cost of Goods Sold (Line 2)
**If Partnership Has Inventory:**

**COGS Calculation (from Form 1125-A):**
```
Line 1: Inventory at beginning of year (ties to prior year ending)
Line 2: Purchases during year
Line 3: Cost of labor
Line 4: Additional §263A costs
Line 5: Other costs
Line 6: Total (sum Lines 1-5)
Line 7: Inventory at end of year (ties to Schedule L Line 3)
Line 8: COGS (Line 6 minus Line 7)

Line 8 flows to Form 1065 Line 2
```

**Inventory Method Verification:**
```
Check box on Form 1125-A:
□ FIFO (First-In, First-Out)
□ LIFO (Last-In, First-Out)
□ Average Cost
□ Other

Method must be:
1. Consistent with prior years (unless Form 3115 filed)
2. Properly applied to inventory valuation
3. Same method for tax and books (unless LIFO used)
```

**Gross Profit Margin Test:**
```
Gross Profit Margin = (Sales - COGS) ÷ Sales

Expected by Industry:
- Retail: 25-50%
- Manufacturing: 20-40%
- Service: 50-80%
- Wholesale: 10-30%

Flag if outside expected range for industry
```

**§263A Uniform Capitalization Rules:**
```
Does partnership:
- Produce real/tangible personal property, OR
- Acquire property for resale with average annual gross receipts > $29M?

├─ YES → §263A applies
│   └─ Additional costs must be capitalized into inventory
│       (indirect labor, overhead, storage, etc.)
└─ NO → §263A doesn't apply
```

**Pass Criteria:** COGS properly calculated, inventory method consistent, gross margin reasonable
**Fail Criteria:** Inventory doesn't tie to prior/current year, method changed without Form 3115, margin unreasonable

### 3.3 Guaranteed Payments (Line 10)
**Critical Partnership Concept:**

**What Are Guaranteed Payments?**
```
Payments to partners for:
- Services rendered to partnership, OR
- Use of capital

Paid WITHOUT REGARD to partnership income

Characteristics:
✓ Deductible by partnership (unlike distributions)
✓ Taxable to receiving partner as ordinary income
✓ Reduces partnership ordinary income (Line 1)
✓ Separately stated on K-1 Box 4
```

**Verification Procedure:**
1. Identify all guaranteed payments from books/partnership agreement
2. Verify total on Line 10 of Form 1065
3. For EACH partner receiving guaranteed payments:
   ```
   Partner A K-1 Box 4: $_______
   Partner B K-1 Box 4: $_______
   Partner C K-1 Box 4: $_______
   TOTAL:               $_______ ← Must equal Form 1065 Line 10
   ```
4. Verify amounts tie to partnership agreement
5. Check if payments are reasonable for services rendered

**Common Error:**
```
WRONG: Treating guaranteed payment as distribution
- Distributions are NOT deductible
- Distributions do NOT go on Line 10
- Distributions shown only on K-1 Line 19

RIGHT: Guaranteed payment deducted on Line 10
       AND shown on K-1 Box 4
```

**Pass Criteria:** Guaranteed payments properly deducted, tie to K-1s, reasonable for services
**Fail Criteria:** Mismatch with K-1s, unreasonably high/low, confused with distributions

### 3.4 Depreciation (Line 16a)
**Procedure:**
1. Verify Form 4562 attached
2. Review depreciation methods used:
   - MACRS (Modified Accelerated Cost Recovery System)
   - Bonus depreciation
   - §179 expensing

**§179 Expensing:**
```
2024 Limits:
- Maximum deduction: $1,220,000
- Phase-out threshold: $3,050,000

Calculation:
If cost of qualified property > $3,050,000:
   Reduce $1,220,000 by amount over threshold
   
§179 CANNOT create loss (limited to taxable income)
Excess carries forward

CRITICAL: §179 is separately stated on K-1 Box 12
Must be added back to ordinary income calculation
```

**Bonus Depreciation:**
```
Qualified property placed in service:
- 2023 and later: 80% bonus (declining)
- Applies to new and used property (post-TCJA)
- Taken after §179 but before regular MACRS

Verify:
✓ Property qualifies (5, 7, 10, 15, 20-year property)
✓ Percentage correct for year
✓ Applied after §179 election
```

**Listed Property (Part V):**
```
Special rules for:
- Vehicles
- Computers (pre-2018)
- Cell phones (pre-2010)

Require proof of business use percentage:
- <50% business use → No bonus, no §179, straight-line only
- ≥50% business use → Normal depreciation methods allowed
- 100% business use → Needs strong documentation
```

**Depreciation Reconciliation:**
```
Form 4562 total depreciation
MUST equal
Form 1065 Line 16a + any §179 on K-1 Box 12

If mismatch → Find error before proceeding
```

**Pass Criteria:** Form 4562 present, methods proper, depreciation reasonable, §179 separately stated
**Fail Criteria:** Missing Form 4562, §179 not separately stated, business use % unsupported

### 3.5 Interest Expense and §163(j) Limitation (Line 15)
**Interest Expense Verification:**
1. Total interest paid during year
2. Trace to: Business loans, mortgages on business property
3. Verify NOT personal interest or investment interest (separately stated)

**§163(j) Business Interest Limitation:**
```
APPLIES IF:
Partnership has average annual gross receipts > $30M (3-year average)

Limitation:
Deductible Interest = 30% × Adjusted Taxable Income (ATI)
Excess interest disallowed (carries forward)

ATI Calculation:
Taxable income before:
+ Business interest expense
+ Business interest income
+ NOL deduction
+ §199A deduction
+ Depreciation/amortization (for tax years 2023+)

If §163(j) applies → Form 8990 required
```

**Pass Criteria:** Interest properly classified, §163(j) applied if required, Form 8990 present
**Fail Criteria:** Investment interest not separated, §163(j) missed for large partnership

## Step 4: Separately Stated Items (Schedule K)

**Critical Concept: Some items CANNOT be included in ordinary income**
**They must be separately stated because partners may have different tax treatment**

### 4.1 Schedule K - Partnership-Level Totals
**Procedure: Verify EACH line of Schedule K:**

**Line 1: Ordinary Business Income/Loss**
```
This is from Form 1065 Analysis (Schedule K) Line 1
= Gross income - deductions
= Partnership ordinary income before separately stated items

Should tie to Form 1065 Page 1 Line 22 (Ordinary business income)
```

**Lines 2-3: Net Rental Real Estate & Other Rental Income**
```
Why separately stated?
- Subject to passive activity loss rules
- Different treatment for real estate professionals
- At-risk limitations may apply

Verify rental income/expenses properly separated from other business activity
```

**Lines 4-5: Interest and Dividends**
```
Why separately stated?
- May be investment income for:
  - Net investment income tax (Form 8960)
  - Investment interest expense limitation
- Qualified dividends get preferential rates at partner level

Verify:
✓ Interest on Line 4 ties to 1099-INTs
✓ Qualified dividends properly identified on Line 5b
```

**Lines 7-8: Royalties**
```
Why separately stated?
- Passive income for most partners
- May be subject to NIIT
- Depletion calculated at partner level
```

**Lines 9-10: Capital Gains and §1231 Gains**
```
Why separately stated?
- Taxed at preferential capital gains rates
- Different holding period rules
- Capital loss limitations at partner level

Verify Form 8949 and Schedule D attached if applicable
Check §1231 gain/loss reported on Form 4797
```

**Line 11: Other Income/Loss**
```
Catch-all for items not fitting above categories:
- §481 adjustments
- Cancellation of debt income
- Recoveries of prior deductions
- Gambling income
- Etc.

Review attached statement for details
```

**Line 12: §179 Deduction**
```
WHY SEPARATELY STATED:
Partners subject to individual limitations:
- $1,220,000 maximum (2024)
- Limited to taxable income at partner level
- Phase-out if partner has > $3,050,000 total property

Verify:
✓ Amount ties to Form 4562 Line 12
✓ Each partner's K-1 Box 12 allocation
✓ Sum of all K-1 Box 12 = Schedule K Line 12
```

**Line 13: Charitable Contributions**
```
WHY SEPARATELY STATED:
Percentage limitations apply at partner level:
- Cash: 60% of partner's AGI
- Property: 30% or 20% depending on type

Verify:
✓ Substantiation on file (receipts, Form 8283 if >$500 non-cash)
✓ Allocations to partners reasonable
✓ Sum of K-1 Box 13A = Schedule K Line 13
```

**Line 14: §179 Expense Deduction**
```
Wait, isn't this Line 12?
No - this is for certain property types, Line 12 is standard §179

Check codes and verify proper classification
```

**Pass Criteria:** All separately stated items properly identified, totals tie to supporting forms
**Fail Criteria:** Items improperly included in ordinary income, missing supporting schedules

## Step 5: Partner Capital Account & K-1 Review

### 5.1 Partner Capital Account Reconciliation
**For EACH Partner, Capital Account Must Reconcile:**

```
PARTNER CAPITAL ACCOUNT FLOW:

Beginning Capital (from prior year K-1)
+ Capital contributions (cash and property FMV)
+ Share of income items (ordinary + separately stated)
+ Share of tax-exempt income
- Distributions (cash and property FMV)
- Share of loss items (ordinary + separately stated)
- Share of non-deductible expenses
= Ending Capital (on current year K-1)

MUST RECONCILE FOR EACH PARTNER
```

**Three Methods of Capital Account Maintenance:**

**Method 1: Tax Basis (IRC §705)**
```
Most common method
Tracks partner's tax basis in partnership interest

Increases:
+ Cash contributed
+ Adjusted basis of property contributed
+ Share of partnership income/gains
+ Share of partnership liabilities (increases basis)

Decreases:
- Cash distributed
- Adjusted basis of property distributed
- Share of partnership losses/deductions
- Share of partnership liabilities (decreases basis)
- Share of non-deductible expenses
```

**Method 2: GAAP (Book Capital)**
```
Financial accounting method
Tracks book value of partner's equity

Uses FMV for contributions/distributions
May differ from tax basis
Simpler but less useful for tax purposes
```

**Method 3: §704(b) (Substantial Economic Effect)**
```
Required for partnerships with special allocations
Most complex and detailed
Tracks "substantial economic effect" of items

Required to maintain:
✓ Capital accounts according to regulations
✓ Liquidation proceeds per capital account
✓ Deficit restoration obligation
```

**Verification Steps:**
1. Identify which method partnership uses (should be checked on K-1)
2. For each partner, verify:
   ```
   Prior year ending capital = Current year beginning capital
   ```
3. Verify all items flow through:
   - Contributions on K-1 Line 16
   - Distributions on K-1 Line 19
   - Income/loss allocations
4. Calculate ending capital
5. Verify ending capital on K-1 Line 20 (L)

**Common Errors:**
- Mixing methods (some partners tax basis, others GAAP)
- Distributions not reducing capital
- Contributions not increasing capital
- Prior year mismatch (beginning ≠ prior ending)

**Pass Criteria:** Each partner's capital reconciles, method consistent, ties to prior year
**Fail Criteria:** Capital doesn't reconcile, negative capital unexplained, method inconsistent

### 5.2 Partner Basis Tracking (Critical!)
**Partner's Outside Basis vs Capital Account:**

```
THEY ARE NOT THE SAME (usually)

Capital Account = Partner's equity per partnership books
Outside Basis = Partner's tax basis in partnership interest

Basis is critical for determining:
- Loss limitations
- Tax on distributions
- Gain/loss on sale of interest
```

**Partner Basis Calculation:**
```
Beginning Basis (from prior year)
+ Capital contributions
+ Share of partnership income (all types)
+ Share of tax-exempt income
+ Increase in share of partnership liabilities
- Distributions received
- Share of partnership losses (all types)
- Share of non-deductible expenses
- Decrease in share of partnership liabilities
= Ending Basis

PARTNER BASIS CANNOT GO NEGATIVE
If losses exceed basis → Losses suspended (carry forward)
```

**Liability Allocation - Increases Basis:**

**Recourse Liabilities:**
```
Allocated to partners who bear economic risk of loss

Who bears risk?
- Partner who would have to pay if partnership defaulted
- Partners with deficit restoration obligations (DRO)
- Guaranteed the debt

Example:
Partnership has $100k loan, Partner A guaranteed
→ Partner A gets $100k basis increase
→ Other partners get $0 from this liability
```

**Nonrecourse Liabilities:**
```
No partner bears risk (lender's only recourse is property)

Allocated per:
1. §704(c) built-in gain (if property contributed)
2. §704(b) share of profits
3. General partner interests

Example:
Partnership has $100k nonrecourse loan
Partners share profits 60/40
→ Partner A gets $60k basis increase
→ Partner B gets $40k basis increase
```

**Qualified Nonrecourse Financing (Real Estate):**
```
Special category for real estate:
- Loan is nonrecourse
- But secured by real property
- From qualified lender

Allocated to partners who bear the economic risk of loss
 from the specific property
```

**Basis Limitation Application:**
```
If partner's share of losses > basis:

1. Calculate available basis
2. Deduct losses up to basis
3. Suspend excess losses
4. Track suspended losses separately
5. Carry forward indefinitely
6. Use when basis increases in future years

K-1 Part III Item L should check "Yes" if basis limitation applies
```

**Pass Criteria:** Basis tracked for each partner, loss limitations applied, liabilities properly allocated
**Fail Criteria:** Losses exceed basis without suspension, liability allocation missing

### 5.3 Schedule K-1 Accuracy Verification
**For EACH K-1, Verify:**

#### Part I - Information About the Partnership
- [ ] Partnership name, address, EIN match Form 1065
- [ ] IRS Center where partnership files
- [ ] Check box for final K-1 if partner left during year

#### Part II - Information About the Partner
- [ ] Partner name, address, TIN present and correct
- [ ] Partner type identified (individual, corporation, trust, etc.)
- [ ] Domestic/foreign partner designation
- [ ] **Profit, loss, and capital sharing percentages**
  ```
  CRITICAL: Sum across all K-1s must equal 100% for each
  
  Example verification:
  Partner A: 40% profit, 40% loss, 40% capital
  Partner B: 35% profit, 35% loss, 35% capital
  Partner C: 25% profit, 25% loss, 25% capital
  TOTALS:   100%      100%      100%      ✓ CORRECT
  ```
- [ ] Beginning and ending capital account amounts
- [ ] Capital account method disclosed (tax basis, GAAP, §704(b))

#### Part III - Partner's Share of Items
**For each box, verify:**

**Box 1 - Ordinary Business Income/Loss:**
```
= Partner's % × Schedule K Line 1

If special allocation:
- Must have substantial economic effect
- Documented in partnership agreement
- Different from profit-sharing %

Sum of all K-1 Box 1 MUST equal Schedule K Line 1
```

**Box 2-3 - Rental Income:**
```
Partner's share × Schedule K Lines 2-3
Check if passive activity designation correct:
- Limited partners → Usually passive
- General partners → Apply material participation tests
```

**Box 4 - Guaranteed Payments:**
```
Payments to THIS partner for services/capital
Should match partnership agreement
NOT allocated by profit-sharing % (it's fixed payment)

Sum of all K-1 Box 4 must equal Form 1065 Line 10
```

**Box 5 - Interest Income:**
```
Partner's share of partnership interest income
Goes to Schedule B on partner's 1040 (even if <$1,500)
Forces Schedule B to be filed
```

**Boxes 6-11 - Other Separately Stated Items:**
```
Each allocated per partner's profit-sharing % (unless special allocation)
Verify sum of all K-1s = Schedule K for each line
```

**Box 12 - §179 Deduction:**
```
Partner's share of §179
Partners must apply their individual limitations:
- $1,220,000 max
- Limited to taxable income at partner level
- Phase-out if partner's total §179 property > $3,050,000

Code A: §179 deduction
Verify sum of all K-1 Box 12 = Schedule K Line 12
```

**Box 13 - Credits:**
```
Various credits flow through with codes:
A: Low-income housing credit
B: Qualified rehabilitation expenditures
C-P: Other credits

Check codes match attached statements
Verify allocations reasonable
```

**Box 16 - Foreign Transactions:**
```
If partnership has foreign activities:
- Name of country
- Gross income from sources
- Deductions allocated
- Foreign taxes paid

Partners may need Form 1116 or 1118
```

**Box 19 - Distributions:**
```
Cash and property distributed to THIS partner
Reduces partner's capital account and basis
Check timing (date distributed affects allocation of income/loss)

If distribution > basis → Partner recognizes gain
```

**Box 20 - Other Information:**
```
State/local items for partner's state returns:
- State/local income
- State/local withholding
- State modifications (add-backs, subtractions)

Critical for multi-state partnerships
```

**Pass Criteria:** All K-1s complete, allocations tie to Schedule K, percentages total 100%
**Fail Criteria:** Allocations don't tie, percentages don't total 100%, missing information

## Step 6: Complex Partnership Issues

### 6.1 Disguised Sales (§707(a)(2)(B))
**The Rule: Contribution followed by distribution may be taxable sale**

**When to Test for Disguised Sale:**
```
Did partner contribute property AND receive distribution within 2 years?
├─ YES → Apply presumptions:
│   ├─ Distribution within 2 years of contribution → PRESUMED sale
│   │   (unless partnership can rebut)
│   └─ Distribution >2 years after contribution → PRESUMED NOT sale
│       (but IRS can argue otherwise if facts indicate sale)
└─ NO → Not a disguised sale
```

**Red Flags:**
```
✓ Partner contributes appreciated property
✓ Partnership takes on debt secured by property
✓ Partnership distributes cash to contributing partner shortly after
✓ Negotiations discussed sale price before contribution
✓ Distribution tied to value of contributed property
```

**Tax Consequences if Disguised Sale:**
```
Partner recognizes gain on "sale":
- Selling price = Cash received + liabilities assumed by partnership
- Less: Partner's adjusted basis in property
- = Taxable gain

This is MAJOR tax event, not just basis adjustment
```

**Verification Procedure:**
1. Review all contributions during current and prior 2 years
2. Review all distributions during current and following 2 years
3. Match contributions to distributions by partner
4. If potential disguised sale identified:
   - Review partnership agreement
   - Review contemporaneous documents
   - Determine if sale treatment applies
5. If sale occurred, verify gain properly recognized

**Pass Criteria:** Disguised sale rules considered, transactions properly characterized
**Fail Criteria:** Obvious disguised sale not recognized, gain not reported

### 6.2 Hot Assets (§751)
**The Rule: Certain assets create ordinary income on distribution or sale**

**What Are Hot Assets?**
```
1. Unrealized Receivables:
   - Accounts receivable (accrual basis)
   - Rights to payment for services
   - Depreciation recapture potential
   - Mining property recapture

2. Inventory Items:
   - Property held for sale to customers
   - Property that would be inventory if sold
   - Property held <3 years (certain types)
```

**Why It Matters:**
```
Normal rule: Partner recognizes capital gain on sale of partnership interest

Hot assets rule: Portion attributable to hot assets is ORDINARY INCOME

This converts what would be capital gain to ordinary income
Partner pays higher tax rate on ordinary income portion
```

**When Rule Applies:**
```
1. Sale of partnership interest:
   Buyer and seller must allocate price:
   - Ordinary income portion (hot assets)
   - Capital gain portion (other assets)
   
2. Distribution to partner:
   If distribution changes partner's share of hot assets:
   - May create ordinary income recognition
   - Even if no cash received!
```

**Verification Procedure:**
1. Identify if partnership has hot assets:
   ```
   Review balance sheet for:
   - Accounts receivable (if accrual basis)
   - Inventory
   - Depreciation recapture potential
   ```
2. If partner sold interest during year:
   - Verify Form 8308 filed by partnership
   - Check ordinary income portion calculated
3. If large distribution occurred:
   - Check if distribution disproportionate
   - Verify hot asset rules considered

**Pass Criteria:** Hot assets identified, distributions analyzed, sale properly reported
**Fail Criteria:** Partner sale without Form 8308, hot assets not identified, ordinary income missed

### 6.3 Built-in Gain/Loss - §704(c) Property
**The Rule: Property contributed with FMV ≠ basis creates built-in gain/loss**

**When §704(c) Applies:**
```
Partner contributes property:
Fair Market Value: $100,000
Partner's Basis:    $ 60,000
Built-in Gain:      $ 40,000

This $40,000 built-in gain must be allocated back to contributing partner
```

**Three Methods to Allocate §704(c):**

**1. Traditional Method:**
```
Contributing partner allocated built-in gain/loss
Other partners share post-contribution gain/loss

Example:
Property contributed with $40k built-in gain
Partnership sells for $120k (total gain $60k)

Allocation:
Contributing partner: $40k (built-in) + $10k (post-contribution share)
Other partner: $10k (post-contribution share)
Total: $60k
```

**2. Traditional Method with Curative Allocations:**
```
Allows curative allocations of other income to achieve fairness
More flexible than straight traditional method
```

**3. Remedial Method:**
```
Creates fictional income to achieve proper allocations
Most favorable to non-contributing partners
Most complex to administer
```

**Verification Procedure:**
1. Review partnership agreement for §704(c) method elected
2. Identify all contributed property:
   ```
   For each property:
   - Date contributed
   - FMV at contribution
   - Contributing partner's basis
   - Built-in gain or loss
   - Method of allocation
   ```
3. If contributed property sold or depreciated:
   - Verify allocations follow elected method
   - Check contributing partner received built-in gain/loss
4. Maintain §704(c) layer for life of property

**Common Error:**
```
WRONG: Allocating all gain/loss per profit-sharing ratio
RIGHT: Built-in gain/loss to contributing partner first,
       then remaining per profit-sharing ratio
```

**Pass Criteria:** All contributed property tracked, §704(c) method disclosed, allocations correct
**Fail Criteria:** Built-in gain/loss not tracked, improper allocation method

### 6.4 Partnership Debt Allocation
**The Rule: Partner's share of partnership liabilities increases basis**

**Why It Matters:**
```
Partner Basis = Capital + Share of Liabilities

Higher basis allows:
- Larger loss deductions
- More distributions without gain
- Lower gain on sale of interest
```

**Classification of Debt:**

**1. Recourse Liabilities:**
```
Partner bears economic risk of loss if partnership defaults

Allocation method:
1. Identify which partners have obligation to pay if default
2. Consider:
   - Personal guarantees
   - Deficit restoration obligations (DRO)
   - Related party status
3. Allocate to partners who would pay

Example:
Partnership has $100k recourse loan
Partner A personally guaranteed 100%
→ Partner A gets $100k basis increase
→ Partner B gets $0 from this debt
```

**2. Nonrecourse Liabilities:**
```
No partner bears risk (lender's only recourse is collateral)

Three-tier allocation:
Tier 1: Partner's share of §704(c) gain in property securing debt
Tier 2: Partner's share of §704(b) minimum gain
Tier 3: Remainder per profit-sharing ratio

Usually simplifies to profit-sharing ratio
```

**3. Qualified Nonrecourse Financing:**
```
Special category for real estate:
- Nonrecourse to partners
- Borrowed for real property
- From qualified lender
- Lender commercially reasonable

Treated like recourse for at-risk purposes
Allocated to partners who bear risk of loss on property
```

**Verification Procedure:**
```
1. Obtain partnership's debt schedule:
   Loan              Amount      Type            Security
   Bank loan 1       $500,000    Recourse        General obligation
   Bank loan 2       $1,000,000  Nonrecourse     Real property
   Related party     $200,000    Recourse        Personal guarantee
   Total             $1,700,000

2. For EACH loan, determine allocation:
   - Recourse: Who guaranteed? Who has DRO?
   - Nonrecourse: §704(c) gain? Else profit-sharing ratio
   
3. Calculate each partner's share:
   Partner A: $500k recourse (guaranteed) + 60% of $1M NR = $1,100k
   Partner B: $0 recourse + 40% of $1M NR = $400k
   Total: $1,500k

4. Verify K-1 Part II Item K shows share of liabilities

5. Verify sum across all partners = total partnership liabilities
```

**Common Errors:**
- Allocating all debt per profit-sharing (wrong for recourse)
- Not considering guarantees
- Forgetting debt creates basis
- Nonrecourse debt not allocated at all

**Pass Criteria:** All debt classified, properly allocated, K-1s show shares, total ties
**Fail Criteria:** Debt allocation missing, improper classification, doesn't total to partnership liabilities

## Step 7: State Compliance

### 7.1 Multi-State Nexus Determination
**Procedure: Identify ALL states where partnership has nexus**

**Nexus Creates Filing Requirement:**

**Physical Presence Nexus:**
```
Partnership has nexus if:
✓ Office or place of business in state
✓ Employee working in state
✓ Owned/leased property in state
✓ Inventory in state (including consignment)
✓ Regular business activity in state
```

**Economic Nexus:**
```
Many states now have economic nexus thresholds:

Common Standards:
- Gross receipts from state > $100,000 to $500,000, OR
- 200+ separate transactions in state

States with Economic Nexus (examples):
- California: $610,395 (2024)
- New York: $1,000,000
- Texas: $500,000
- Ohio: $150,000 or 200 transactions

Check EACH state where partnership has sales
```

**Factor Presence Nexus:**
```
Some states: Nexus if exceed threshold in any single factor:
- Sales (dollars or transactions)
- Property (value)
- Payroll (amount)

Example thresholds:
- $50,000 property in state
- $50,000 payroll in state
- $500,000 sales in state
```

**Verification Steps:**
1. List all states where partnership has:
   - Physical location
   - Employees
   - Property
   - Sales
2. For each state, determine if nexus thresholds exceeded
3. Create state filing matrix:
   ```
   State | Nexus? | Gross Receipts | Return Required? | Filed?
   OH    | Yes    | $2,500,000    | Yes             | ✓
   KY    | Yes    | $850,000      | Yes             | ✓
   IN    | No     | $45,000       | No              | N/A
   ```

**Pass Criteria:** All nexus states identified, returns filed where required
**Fail Criteria:** Missing state returns, nexus not considered

### 7.2 State Apportionment
**For Multi-State Partnerships, Apportion Income to Each State:**

**Three-Factor Formula (Traditional):**
```
Apportionment % = (Sales Factor + Payroll Factor + Property Factor) ÷ 3

Sales Factor = State Sales ÷ Total Sales
Payroll Factor = State Payroll ÷ Total Payroll
Property Factor = State Property ÷ Total Property
```

**Single-Factor Formula (Modern Trend):**
```
Many states now use ONLY sales factor:
Apportionment % = State Sales ÷ Total Sales

Common in:
- California
- Texas
- Most states post-2010
```

**Sales Factor Sourcing Rules:**

**Cost-of-Performance (Old Rule):**
```
Sale sourced to state where income-producing activity occurred
"Where did we do the work?"
```

**Market-Based Sourcing (New Rule):**
```
Sale sourced to state where customer located/benefit received
"Where is our customer?"

Now adopted by most states
More taxpayer-favorable (spreads income to more states)
```

**Throwback Rule:**
```
If sale made to state where partnership has NO nexus:
Some states require "throwing back" to origin state

Example:
Partnership in OH sells to customer in FL
FL has no nexus
OH has throwback rule
→ Sale counts in OH sales factor even though customer in FL
```

**Verification Procedure:**
1. For each state return, verify apportionment schedule:
   ```
   Sales Factor:
   - Numerator (state sales)
   - Denominator (total everywhere sales)
   - Verify sourcing method correct (market-based vs cost-of-performance)
   
   Payroll Factor:
   - Numerator (state W-2 wages)
   - Denominator (total W-2 wages)
   
   Property Factor:
   - Numerator (state property average value)
   - Denominator (total property average value)
   ```

2. Verify factor weights correct for state:
   ```
   Traditional: 1/3, 1/3, 1/3
   Double-weighted sales: 0.5, 0.25, 0.25
   Single-sales: 1.0, 0, 0
   ```

3. Check that apportionment % reasonable:
   ```
   Sum of all state apportionment %s should be approximately 100%
   (May be more or less due to state differences)
   ```

**Pass Criteria:** Apportionment factors calculated correctly, sourcing rules proper for each state
**Fail Criteria:** Wrong formula used, sourcing errors, factors don't reconcile

### 7.3 Composite Returns & Withholding
**For Nonresident Partners:**

**Composite Return Option:**
```
Partnership files single composite return including all nonresident partners

Benefits:
✓ Partners don't have to file individual state returns
✓ Simplifies compliance for partners
✓ Partnership pays tax on behalf of partners

Requirements:
- All participants must consent
- Tax paid at highest rate (no deductions for partners)
- Not all states allow
```

**State Withholding Requirements:**
```
Many states REQUIRE partnerships to withhold on nonresident partners:

Common rates: 3-8% of partner's share of income

Example:
Partner B (NY resident) in OH partnership
OH taxable income allocated to Partner B: $50,000
OH withholding rate: 5%
Partnership must withhold: $50,000 × 5% = $2,500
Remit to OH Dept of Taxation

Partner B claims withholding as credit on OH nonresident return
```

**Verification Checklist:**
```
For EACH nonresident partner:
- [ ] Composite return filed OR individual return required
- [ ] State withholding calculated and remitted
- [ ] K-1 Box 20 shows state withholding
- [ ] Form sent to partner documenting withholding
```

**Pass Criteria:** Nonresident partners properly handled, withholding calculated and remitted
**Fail Criteria:** Withholding not remitted, composite return errors, K-1s missing state info

## Step 8: Quality Control & Common Errors

### 8.1 Partnership-Level Math Verification
**Cross-Check All Totals:**

```
Schedule K (Partnership Level) Verification:

Line 1: Ordinary income → Must tie to Form 1065 Page 1 Line 22

Lines 3-11: Separately stated items → Verify each has support:
- Schedule attached
- Reasonable for business type
- Properly allocated to partners

Line 12: §179 → Must tie to Form 4562

Schedule L: 
- Assets must equal Liabilities + Capital
- Capital must equal Schedule M-2 Line 8
```

### 8.2 K-1 Summation Verification
**CRITICAL CHECK: For EACH line, sum of all K-1s must equal Schedule K**

```
Example Verification:
Schedule K Line 1 (Ordinary income): $150,000

Partner A K-1 Box 1: $60,000
Partner B K-1 Box 1: $50,000
Partner C K-1 Box 1: $40,000
TOTAL:              $150,000  ✓ MATCHES

If doesn't match → Find error before proceeding
This is #1 cause of rejected partnership returns
```

**Verify for EVERY separately stated item:**
- Box 1: Ordinary income
- Box 2-3: Rental income
- Box 4: Guaranteed payments
- Box 5: Interest
- Box 6a-6b: Dividends
- Box 7: Royalties
- Box 9: Capital gains
- Box 12: §179
- Box 13: Credits
- Etc.

### 8.3 Ownership Percentage Verification
**Percentages Must Total 100%:**

```
For EACH type of percentage:

Profit %:
Partner A: 40%
Partner B: 35%
Partner C: 25%
TOTAL:    100%  ✓

Loss %:
Partner A: 40%
Partner B: 35%
Partner C: 25%
TOTAL:    100%  ✓

Capital %:
Partner A: 40%
Partner B: 35%
Partner C: 25%
TOTAL:    100%  ✓

If doesn't total 100% → ERROR, cannot file
```

### 8.4 Common Partnership Errors
**Final Sweep for These Frequent Mistakes:**

**1. Capital Accounts**
- [ ] Beginning capital ≠ prior year ending capital
- [ ] Capital accounts don't sum to Schedule L equity
- [ ] Distributions not reducing capital
- [ ] Negative capital without explanation

**2. Guaranteed Payments**
- [ ] Not deducted on Form 1065 Line 10
- [ ] Not shown on partner's K-1 Box 4
- [ ] Confused with distributions
- [ ] Sum of K-1s ≠ Form 1065 Line 10

**3. Separately Stated Items**
- [ ] §179 included in ordinary income (should be Box 12)
- [ ] Charitable contributions not separately stated
- [ ] Interest/dividends included in ordinary income

**4. K-1 Allocations**
- [ ] Sum of all K-1s ≠ Schedule K
- [ ] Percentages don't total 100%
- [ ] Special allocations without substantial economic effect

**5. Basis & Liabilities**
- [ ] Liabilities not allocated to partners
- [ ] Sum of K-1 liabilities ≠ Schedule L liabilities
- [ ] Loss limitation not applied when losses > basis

**6. State Issues**
- [ ] Nexus states not identified
- [ ] Withholding not remitted for nonresident partners
- [ ] K-1 Box 20 missing state information

**7. Schedule M-1/M-2**
- [ ] M-1 doesn't balance
- [ ] M-2 doesn't tie to Schedule L capital
- [ ] Capital account method not disclosed

**Pass Criteria:** None of common errors present, all cross-checks verified
**Fail Criteria:** Any common error found
