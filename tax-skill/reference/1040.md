# Form 1040 Review Workflow

## Step 1: Initial Document Verification

### 1.1 Verify Taxpayer Identification
**Procedure:**
1. Locate taxpayer name at top of Form 1040
2. Verify SSN is present and formatted correctly (XXX-XX-XXXX)
3. If prior year return available, compare name and SSN match exactly
4. Check address - flag if changed from prior year (may indicate state residency issue)

**What to Look For:**
- Misspelled names that won't match IRS records
- Transposed SSN digits
- Address changes crossing state lines

**Pass Criteria:** Name and SSN present, properly formatted, match IRS records
**Fail Criteria:** Missing SSN, obvious errors, mismatches with W-2s/1099s

### 1.2 Validate Filing Status
**Procedure:**
1. Identify filing status checkbox on Form 1040 (Single, MFJ, MFS, HOH, QW)
2. If Married Filing Jointly: Verify both spouse names and SSNs present
3. If Head of Household: Verify qualifying person identified and relationship shown
4. If Married Filing Separately: Check if spouse name and SSN provided
5. Cross-reference to prior year - if changed, determine if change is appropriate

**Decision Tree:**
```
Is taxpayer married? 
├─ YES → Is MFJ or MFS checked?
│   ├─ MFJ → Verify both spouses signed return
│   └─ MFS → Verify spouse info provided, document reason for MFS
└─ NO → Is Single or HOH checked?
    ├─ Single → Verify no dependents qualify for HOH
    └─ HOH → Verify qualifying person listed and relationship qualifies
```

**Pass Criteria:** Filing status matches marital status and household facts
**Fail Criteria:** Inconsistent with facts, missing required information

### 1.3 Review Dependent Information
**Procedure:**
1. Count dependents listed in dependent section
2. For EACH dependent, verify:
   - Full name provided
   - Valid SSN present (not ITIN unless qualifying)
   - Relationship to taxpayer stated
   - Checkbox marked for Child Tax Credit if under 17
3. Apply qualifying tests:
   - **Qualifying Child**: Age < 19 (or < 24 if student), lived with taxpayer > 6 months
   - **Qualifying Relative**: Support test (taxpayer provided > 50%), gross income < $4,700

**What to Flag:**
- Dependent over age 17 but CTC checkbox marked
- Missing SSNs (prevents CTC and EITC)
- Same dependent claimed by multiple taxpayers (divorced parents)
- Dependent with income > $4,700 claimed as qualifying relative

**Pass Criteria:** All dependents have complete info and meet qualifying tests
**Fail Criteria:** Missing SSNs, failed qualifying tests, duplicate claims

### 1.4 Verify Prior Year Carryforwards
**Procedure:**
1. Review prior year return if available
2. Identify carryforward items:
   - Capital loss carryforward (Schedule D)
   - Passive activity losses (Form 8582)
   - Net operating losses (rare for individuals)
   - Charitable contribution carryovers
   - Alternative minimum tax credit
3. For each carryforward, verify amount on current year return matches prior year ending balance
4. Check that carryforwards are properly applied (not just sitting unused)

**Calculation Check:**
```
Prior Year Ending Carryforward 
± Current Year Adjustments
- Current Year Utilization
= Current Year Ending Carryforward
```

**Pass Criteria:** All prior year carryforwards identified and properly applied
**Fail Criteria:** Carryforwards missing, incorrect amounts, not utilized when should be

## Step 2: Income Verification

### 2.1 Wages and W-2 Reconciliation (Line 1)
**Procedure:**
1. Locate Line 1 on Form 1040 (wages, salaries, tips)
2. Count number of W-2s included with return
3. For EACH W-2, extract Box 1 (federal wages)
4. Sum all W-2 Box 1 amounts
5. Verify sum equals Line 1 on Form 1040

**Mathematical Check:**
```
W-2 #1 Box 1: $______
W-2 #2 Box 1: $______
W-2 #3 Box 1: $______
TOTAL:        $______  ← Must equal Form 1040 Line 1
```

**Additional W-2 Verification:**
- Box 2 (federal withholding) ties to Line 25 of Form 1040
- Box 12 codes identify retirement contributions, HSA contributions
- Boxes 3 & 5 (SS and Medicare wages) match Box 1 unless pre-tax deductions exist
- State wages in Box 16 tie to state return

**Pass Criteria:** All W-2s accounted for, Box 1 total equals Line 1
**Fail Criteria:** Missing W-2s, math errors, unexplained discrepancies

### 2.2 Interest and Dividend Income (Lines 2-3)
**Procedure:**
1. Locate Lines 2a/2b (tax-exempt and taxable interest)
2. Locate Line 3a/3b (qualified and ordinary dividends)
3. Count 1099-INT and 1099-DIV forms provided
4. Sum all interest from 1099-INTs
5. Sum all dividends from 1099-DIVs

**Schedule B Requirement Check:**
```
Is taxable interest (Line 2b) OR ordinary dividends (Line 3b) > $1,500?
├─ YES → Schedule B MUST be filed
│   └─ Verify Schedule B present and totals tie to Form 1040
└─ NO → Schedule B optional (but recommended for documentation)
```

**Qualified Dividends Verification:**
- Line 3a (qualified dividends) should equal sum of 1099-DIV Box 1b amounts
- Qualified dividends taxed at preferential capital gains rates
- Line 3a amount cannot exceed Line 3b (ordinary dividends)

**Foreign Account Check:**
```
Do 1099-INTs or 1099-DIVs show foreign source income?
├─ YES → Check Schedule B Part III foreign account question answered
│   └─ If foreign accounts exist, verify FBAR and Form 8938 requirements
└─ NO → Proceed with review
```

**Pass Criteria:** All 1099s accounted for, Schedule B filed if required, amounts tie
**Fail Criteria:** Schedule B missing when required, math errors, foreign account disclosure missing

### 2.3 Business Income - Schedule C Review
**Procedure:**
1. Locate Schedule C attached to return
2. Verify each Schedule C contains:
   - Business name and description
   - Principal business code (6-digit NAICS)
   - Accounting method (cash or accrual)
   - EIN (if applicable) or note that SSN used

**Income Verification:**
1. Gross receipts (Line 1) - check for reasonableness vs prior year
2. Returns and allowances (Line 2) - should be small % of gross receipts
3. Cost of goods sold (Line 4) - Part III calculation if inventory business
4. Gross profit margin calculation:
   ```
   Gross Profit = (Line 1 - Line 2 - Line 4) ÷ Line 1
   Expected Range: 20% - 80% depending on industry
   Flag if outside normal range for business type
   ```

**Expense Review - High-Risk Items:**
1. **Home Office Deduction** (Line 30):
   - Form 8829 required for actual expense method
   - Simplified method: $5/sq ft × square footage (max 300 sq ft)
   - Must be regular and exclusive use for business
   - Flag if deduction >20% of home value

2. **Vehicle Expenses** (Line 9):
   - Form 4562 Part V required
   - Check business use percentage (100% business use needs documentation)
   - Verify method: Actual expenses OR standard mileage rate
   - Cannot mix methods in same year

3. **Meals** (Line 24b):
   - 50% limitation generally applied (100% for 2021-2022 only)
   - Should be <3% of gross receipts typically
   - Flag if unusually high

4. **Travel** (Line 24a):
   - Must have business purpose documentation
   - Flag personal vacation destinations

**Self-Employment Tax Check:**
```
Is Schedule C net profit (Line 31) > $400?
├─ YES → Schedule SE MUST be completed
│   ├─ Line 2 of Schedule SE = Line 31 of Schedule C
│   ├─ Self-employment tax = Net profit × 92.35% × 15.3%
│   └─ Verify Schedule SE Line 6 flows to Form 1040 Schedule 2 Line 4
└─ NO → Schedule SE not required
```

**Pass Criteria:** All information complete, SE tax calculated, reasonable expenses
**Fail Criteria:** Missing Schedule SE, 100% business use without documentation, unusual expense ratios

### 2.4 Capital Gains and Losses - Schedule D
**Procedure:**
1. Verify Schedule D present if capital transactions occurred
2. Check for accompanying Form 8949 (required for most transactions)

**Basis Verification:**
```
For EACH transaction on Form 8949:
1. Identify date acquired
2. Identify date sold
3. Calculate holding period:
   - Short-term: ≤ 1 year
   - Long-term: > 1 year
4. Verify basis reported matches 1099-B if broker provided
5. Check for basis adjustments:
   - Wash sales (buying same security within 30 days)
   - Inherited property (step-up to FMV at death)
   - Gift property (carryover basis from donor)
```

**Wash Sale Rule Check:**
```
For each stock sale at a loss:
1. Identify security sold at loss
2. Look for purchase of "substantially identical" security within:
   - 30 days before sale, OR
   - 30 days after sale
3. If found → Loss disallowed, added to basis of new shares
4. Many brokers identify wash sales on 1099-B
```

**Capital Loss Limitation:**
```
If total capital losses exceed capital gains:
1. Maximum deduction against ordinary income = $3,000 ($1,500 if MFS)
2. Excess loss carries forward to next year
3. Verify Schedule D Line 21 shows carryforward amount
4. Check prior year return for carryforward balance
```

**Net Investment Income Tax Check:**
```
Calculate Modified AGI (MAGI):
AGI from Form 1040 Line 11

Is MAGI > Threshold?
├─ Single/HOH: $200,000
├─ MFJ: $250,000
└─ MFS: $125,000

If YES → Form 8960 MUST be completed
   Net Investment Income Tax = 3.8% × Lesser of:
   - Net investment income, OR
   - MAGI excess over threshold
```

**Pass Criteria:** All transactions reported, basis verified, NIIT calculated if required
**Fail Criteria:** Missing Form 8949, wash sales not applied, capital loss carryforward missed, NIIT not calculated

### 2.5 K-1 Income from Partnerships and S Corporations (Schedule E Part II)
**Procedure:**
1. Count all K-1s included with return (Form 1065 and 1120S)
2. Create K-1 tracking grid for each K-1:

```
K-1 Box-by-Box Placement Verification:

Box 1 (Ordinary Income/Loss) → Schedule E Part II Column (h)
   └─ NOT to Schedule C (common error!)

Box 2 (Net Rental Real Estate) → Schedule E Part II Column (g)

Box 3 (Other Net Rental Income) → Schedule E Part II Column (g)

Box 4 (Guaranteed Payments) → Schedule E Part II Column (j)

Box 5 (Interest Income) → Schedule B Line 1 (even if <$1,500)
   └─ Forces Schedule B to be filed

Box 6a (Ordinary Dividends) → Form 1040 Line 3b

Box 6b (Qualified Dividends) → Form 1040 Line 3a

Box 7 (Royalties) → Schedule E Part I

Box 8 (Net Short-Term Capital Gain) → Schedule D Line 5

Box 9a (Net Long-Term Capital Gain) → Schedule D Line 12

Box 9b (Collectibles Gain - 28% rate) → Schedule D Line 18

Box 9c (Unrecaptured §1250 Gain) → Schedule D Line 19

Box 10 (Net §1231 Gain/Loss) → Form 4797

Box 11 (Other Income) → Various (check K-1 codes on attached statement)

Box 12 (§179 Deduction) → Form 4562 Line 12

Box 13 (Credits) → Various credit forms (check codes)
   - Code A: Low-income housing credit
   - Code B: Qualified rehabilitation expenditures
   - Code P: Work opportunity credit

Box 14 (Self-Employment Earnings) → Schedule SE

Box 15 (Credits) → Various forms

Box 16 (Foreign Transactions) → Check for Form 1116 or 1118 requirements

Box 17 (AMT Items) → Form 6251

Box 20 (State Items) → State tax return adjustments
```

**Basis Limitation Check:**
```
For EACH K-1 showing a loss:

1. Locate beginning basis (from prior year K-1 or basis schedule)

2. Calculate current year basis:
   Beginning Basis
   + Current year income items
   + Additional capital contributions
   - Distributions received
   - Non-deductible expenses
   = Available Basis Before Losses

3. Apply loss limitation:
   Loss Allowed = LESSER of:
   - K-1 reported loss, OR
   - Available basis
   
4. If loss > basis:
   - Loss suspended (carried forward)
   - Create/update basis tracking schedule
   - Verify software has properly suspended loss

5. Verify K-1 Part III "Basis Limitation" checked if applicable
```

**At-Risk Limitation Check:**
```
If K-1 shows at-risk loss:
1. Form 6198 required
2. At-risk amount generally = Basis - Nonrecourse debt share
3. Loss limited to at-risk amount
4. Suspended losses tracked separately
```

**Passive Activity Loss Rules:**
```
Step 1: Determine if activity is passive
- Limited partners → AUTOMATICALLY passive
- General partners → Apply material participation tests:
  1. 500+ hours in activity? → Non-passive
  2. Substantially all participation? → Non-passive  
  3. 100+ hours AND more than anyone else? → Non-passive
  4. Significant participation activities (SPA) totaling >500 hours? → Non-passive
  5. Material participation 5 of last 10 years? → Non-passive
  6. Personal service activity with material participation any 3 prior years? → Non-passive
  7. Facts and circumstances + 100 hours? → Non-passive

Step 2: If activity is passive
- Passive losses limited to passive income
- Form 8582 MUST be completed
- Unused losses carry forward indefinitely
- Special $25,000 rental loss allowance if AGI < $100k

Step 3: Self-Rental Rule Check
Does taxpayer rent property to own S Corp or partnership?
├─ YES → Rental income RECHARACTERIZED as non-passive
│   └─ Prevents passive loss from other activities offsetting rental income
└─ NO → Normal passive activity rules apply
```

**Pass Criteria:** All K-1 items properly placed, basis limitations applied, Form 8582 completed for passive losses
**Fail Criteria:** K-1 Box 1 on Schedule C, passive losses not limited, basis limitation missed, self-rental rule not applied

### 2.6 Rental Real Estate Income (Schedule E Part I)
**Procedure:**
1. For EACH rental property listed on Schedule E Part I:
   - Physical address provided
   - Days rented vs days personal use disclosed
   - Fair rental days vs actual rental days

**Personal Use Test:**
```
Was property used personally > greater of:
- 14 days, OR
- 10% of rental days?

├─ YES → Mixed-use property
│   ├─ Allocate expenses between rental and personal
│   ├─ Rental deductions limited to rental income
│   └─ Excess becomes personal (non-deductible)
└─ NO → Full rental property, normal rules apply
```

**Active Participation Test (for $25k loss allowance):**
```
Does taxpayer qualify for active participation?
Requirements:
1. Own ≥10% of property
2. Make management decisions (approve tenants, repairs, terms)
3. NOT materially participate (that's higher standard)

If YES and AGI < $100,000:
   Loss allowance = $25,000 - (0.50 × (AGI - $100,000))
   Fully phased out at AGI of $150,000

If NO → Full passive activity rules apply (Form 8582)
```

**Real Estate Professional Status:**
```
Does taxpayer claim to be real estate professional?
Requirements:
1. >750 hours in real property trades or businesses
2. >50% of personal services in real property trades
3. Material participation in each rental activity (or group election)

If claimed but not met → RECHARACTERIZE all rental losses as passive
This is HIGH AUDIT RISK - verify documentation exists
```

**Pass Criteria:** Personal use properly allocated, passive loss rules applied, REP status documented if claimed
**Fail Criteria:** Full losses claimed without active participation or REP status, personal use not allocated

## Step 3: Deduction Review

### 3.1 Standard vs Itemized Deduction Analysis
**Procedure:**
1. Identify which deduction method used:
   - If Schedule A present → Itemized deductions claimed
   - If no Schedule A → Standard deduction used

2. Calculate standard deduction for filing status:
   ```
   2024 Standard Deductions:
   Single: $14,600
   MFJ: $29,200
   MFS: $14,600
   HOH: $21,900
   Additional: +$1,550 if age 65+ or blind (per person)
   ```

3. If Schedule A filed, verify total itemized (Line 17) > standard deduction
   - If not, standard deduction would be better
   - Flag as potential error or confirm taxpayer choice (state tax benefit)

**State Tax Benefit Rule:**
```
Even if itemized deductions ≤ standard deduction:
Consider itemizing if state allows itemized but not standard
Some states follow federal, others don't
Document why itemizing chosen if below standard
```

**Pass Criteria:** Deduction method provides maximum tax benefit
**Fail Criteria:** Sub-optimal deduction method without documented reason

### 3.2 Schedule A Itemized Deductions Review
**When Schedule A Present, Verify Each Category:**

#### Medical and Dental Expenses (Lines 1-4)
**Procedure:**
1. Total medical expenses (Line 1)
2. Calculate 7.5% of AGI (Line 2)
3. Subtract: Line 1 - Line 2 = Deductible amount (Line 3)

**Verification:**
```
Are medical expenses > 7.5% of AGI?
├─ NO → Line 3 should be $0 (no deduction)
│   └─ Flag if amount shown - likely error
└─ YES → Verify calculation:
    Total Medical Expenses - (AGI × 0.075) = Deductible Amount
```

**What Qualifies:**
- Health insurance premiums (if not pre-tax)
- Doctor, dentist, hospital bills
- Prescription medications
- Long-term care insurance (limits apply)
- Medical equipment and supplies

**Pass Criteria:** Calculation correct, only qualified medical expenses included
**Fail Criteria:** Math error, deduction claimed despite not exceeding 7.5% floor

#### State and Local Taxes (Lines 5-7)
**SALT Cap Verification:**
```
SALT LIMITATION (effective 2018-2025):
Maximum deduction = $10,000 ($5,000 if MFS)

Line 5a: State income taxes OR
Line 5b: State sales taxes (cannot claim both)
PLUS
Line 5c: Real estate taxes
PLUS
Line 5d: Personal property taxes
EQUALS
Line 5e: Total SALT

Line 5e CANNOT EXCEED $10,000 ($5,000 if MFS)

Verify Line 7 = Lesser of Line 5e or $10,000
```

**State Tax Choice (Income vs Sales):**
```
Can elect to deduct EITHER state income tax OR state sales tax:
├─ Income Tax (Line 5a):
│   └─ From state return or W-2 Box 17
├─ Sales Tax (Line 5b):
│   ├─ IRS tables based on income and location, OR
│   └─ Actual receipts (rare)
└─ Choose whichever is HIGHER

If both Lines 5a AND 5b have amounts → ERROR (can only choose one)
```

**Real Estate Tax Verification:**
- Line 5c: Property tax from Form 1098 or tax bill
- Must be ad valorem tax (based on property value)
- Assessments for improvements NOT deductible

**Pass Criteria:** SALT cap applied correctly, only income OR sales tax (not both)
**Fail Criteria:** SALT exceeds $10,000 on Line 7, both income and sales tax claimed

#### Home Mortgage Interest (Lines 8-10)
**Procedure:**
1. Locate Form 1098 (Mortgage Interest Statement) for each property
2. Verify Box 1 (mortgage interest paid) ties to Schedule A Line 8a
3. Apply acquisition debt limitations

**Acquisition Debt Limits:**
```
Mortgage must be for acquisition or improvement of home:

Loans originated BEFORE 12/15/2017:
- Limit: $1,000,000 ($500,000 if MFS)

Loans originated AFTER 12/15/2017:
- Limit: $750,000 ($375,000 if MFS)

If mortgage balance > limit:
Interest deduction prorated:
Deductible Interest = Interest Paid × (Limit ÷ Actual Balance)
```

**Home Equity Debt:**
```
Post-TCJA (2018+):
Home equity interest ONLY deductible if:
- Proceeds used to buy, build, or substantially improve home
- Subject to acquisition debt limits above

If used for other purposes (debt consolidation, car, etc.):
- Interest NOT deductible
- Flag if home equity interest claimed
```

**Points Deduction (Line 8c):**
- Points paid on home purchase: Deductible in year paid
- Points on refinance: Amortize over life of loan
- Verify proper treatment

**Pass Criteria:** Interest from Form 1098, within acquisition debt limits, proper use verified
**Fail Criteria:** Exceeds limits without proration, home equity for non-home purposes

#### Charitable Contributions (Lines 11-14)
**Substantiation Requirements:**

```
Contribution Type | Substantiation Required
------------------|------------------------
< $250           | Bank record or receipt
≥ $250           | Written acknowledgment from charity with:
                 | - Amount donated
                 | - Statement of goods/services provided
                 | - Good faith estimate of value received
≥ $500 (non-cash)| Form 8283 Section A
> $5,000 (non-cash)| Form 8283 Section B + qualified appraisal
> $500,000 (non-cash)| Appraisal must be attached
```

**Percentage Limitations:**
```
Cash Contributions:
- To 50% organizations (most charities): 60% of AGI
- To 30% organizations (private foundations): 30% of AGI
- Excess carries forward 5 years

Non-Cash Contributions:
- Property held >1 year at FMV to 50% org: 30% of AGI
- Property held ≤1 year: Limited to basis
- Capital gain property: 20% of AGI to private foundations
```

**Verification Steps:**
1. Sum cash contributions (Line 11)
2. Verify ≤ 60% of AGI
3. Sum non-cash contributions (Line 12)
4. Verify Form 8283 present if required
5. Check for carry forwards from prior year
6. Calculate current year carryforward if limits exceeded

**Red Flags:**
- Contributions >20% of AGI (audit trigger)
- Large non-cash donations without Form 8283
- Vehicle donations >$500 without Form 1098-C
- Clothing/household items without "good condition or better" certification

**Pass Criteria:** Proper substantiation, percentage limits applied, carryforwards calculated
**Fail Criteria:** Missing Form 8283, exceeds AGI limits without carryforward, inadequate substantiation

### 3.3 Above-the-Line Deductions (Schedule 1)
**These reduce AGI and are often overlooked - verify each:**

#### IRA Contributions (Line 20)
**Procedure:**
1. Verify contribution made by April 15 (or October 15 with extension)
2. Check contribution limits:
   ```
   2024 Limits:
   Under age 50: $7,000
   Age 50+: $8,000 (includes $1,000 catch-up)
   ```
3. Apply phase-out limitations if covered by workplace retirement plan

**Phase-Out Rules:**
```
If taxpayer covered by workplace retirement plan:

Single/HOH:
- Full deduction if MAGI ≤ $77,000
- Partial deduction if MAGI $77,000 - $87,000
- No deduction if MAGI ≥ $87,000

MFJ (both covered):
- Full deduction if MAGI ≤ $123,000
- Partial deduction if MAGI $123,000 - $143,000
- No deduction if MAGI ≥ $143,000

MFJ (spouse covered, taxpayer not):
- Full deduction if MAGI ≤ $230,000
- Partial deduction if MAGI $230,000 - $240,000
- No deduction if MAGI ≥ $240,000
```

**Calculation of Partial Deduction:**
```
Allowable Deduction = Limit × [1 - ((MAGI - Floor) ÷ Phase-out Range)]

Example: Single, MAGI $82,000, age 45
Range: $87,000 - $77,000 = $10,000
Fraction: ($82,000 - $77,000) ÷ $10,000 = 0.50
Deduction: $7,000 × (1 - 0.50) = $3,500
```

**Pass Criteria:** Within limits, phase-out correctly applied if covered by plan
**Fail Criteria:** Exceeds limits, phase-out not applied, late contribution

#### HSA Contributions (Line 13)
**Procedure:**
1. Verify taxpayer had High Deductible Health Plan (HDHP) coverage
2. Check contribution limits:
   ```
   2024 Limits:
   Self-only: $4,150
   Family: $8,300
   Age 55+ catch-up: +$1,000
   ```
3. Prorate if HDHP coverage < 12 months
4. Reduce by employer contributions (from W-2 Box 12 Code W)

**HDHP Requirements:**
```
Minimum deductible:
- Self-only: $1,600
- Family: $3,200

Maximum out-of-pocket:
- Self-only: $8,050
- Family: $16,100

If health plan doesn't meet requirements → NO HSA contribution allowed
```

**Common Errors:**
- Contributing to HSA while also enrolled in FSA (prohibited)
- Contributing after enrolling in Medicare (prohibited)
- Exceeding limits after employer contribution

**Pass Criteria:** HDHP coverage verified, within limits, employer contribution deducted
**Fail Criteria:** No HDHP, exceeds limits, FSA conflict

#### Student Loan Interest (Line 21)
**Procedure:**
1. Locate Form 1098-E from lender
2. Verify interest paid shown in Box 1
3. Apply $2,500 maximum
4. Apply phase-out based on MAGI

**Phase-Out:**
```
Single/HOH:
- Full deduction if MAGI ≤ $80,000
- Partial if MAGI $80,000 - $95,000
- No deduction if MAGI ≥ $95,000

MFJ:
- Full deduction if MAGI ≤ $165,000
- Partial if MAGI $165,000 - $195,000
- No deduction if MAGI ≥ $195,000
```

**Pass Criteria:** Within $2,500 limit, phase-out applied, Form 1098-E present
**Fail Criteria:** Exceeds $2,500, phase-out not applied

#### Self-Employed Health Insurance (Line 17)
**Procedure:**
1. Verify taxpayer has self-employment income (Schedule C, F, or general partnership K-1)
2. Health insurance premiums paid
3. Deduction limited to net self-employment income

**Limitation:**
```
Maximum Deduction = LESSER of:
- Actual premiums paid, OR
- Net self-employment income

Cannot deduct more than business profit
If Schedule C loss → NO health insurance deduction
```

**Cannot Double-Dip:**
- If eligible for employer plan (including spouse's employer) → No deduction
- Cannot claim both here AND on Schedule A medical expenses

**Pass Criteria:** Limited to SE income, not eligible for employer plan, not double-dipped
**Fail Criteria:** Exceeds SE income, employer coverage available, claimed twice

## Step 4: Credit Review

### 4.1 Child Tax Credit and Additional Child Tax Credit
**Procedure:**
1. Count qualifying children (age < 17 with SSN)
2. Calculate base credit: $2,000 per qualifying child
3. Apply phase-out
4. Calculate refundable portion (Additional Child Tax Credit)

**Qualification Requirements:**
```
For EACH child claimed for CTC:
✓ Age < 17 at end of tax year
✓ Valid SSN (not ITIN)
✓ Relationship: Son, daughter, stepchild, foster child, sibling, or descendant
✓ Lived with taxpayer > half the year
✓ Did not provide > half own support
✓ U.S. citizen, national, or resident alien
✓ Claimed as dependent on return
```

**Phase-Out Calculation:**
```
Phase-out begins at:
MFJ: $400,000
All others: $200,000

Reduction = $50 for each $1,000 (or fraction) over threshold

Example: MFJ with $450,000 AGI, 2 children
Base credit: 2 × $2,000 = $4,000
Excess AGI: $450,000 - $400,000 = $50,000
Reduction: $50 × 50 = $2,500
Allowed credit: $4,000 - $2,500 = $1,500
```

**Additional Child Tax Credit (Refundable):**
```
If credit > tax liability:
Refundable amount = 15% × (Earned Income - $2,500)
Maximum refundable = $1,600 per child (2024)

Must have earned income ≥ $2,500 to claim ACTC
```

**Pass Criteria:** Only children meeting all requirements, phase-out applied, ACTC calculated correctly
**Fail Criteria:** Child without SSN, over age 17, phase-out missed, ACTC without earned income

### 4.2 Earned Income Credit (High-Risk Area)
**Due Diligence Requirements - MUST perform:**
1. Verify earned income within EITC range
2. Verify investment income < $11,000 (2024)
3. Verify qualifying children meet all tests
4. Check prior year EITC disallowance (if applicable, cannot claim for 2-10 years)

**Income Ranges (2024):**
```
# of Children | Max AGI (Single) | Max AGI (MFJ) | Max Credit
0             | $17,640         | $24,210       | $600
1             | $46,560         | $53,120       | $3,995
2             | $52,918         | $59,478       | $6,604
3+            | $56,838         | $63,398       | $7,430
```

**Qualifying Child Tests:**
```
Same as CTC PLUS additional requirements:
✓ Age < 19 (or < 24 if full-time student, or any age if disabled)
✓ Must have lived in U.S. > 6 months
✓ Cannot file joint return (unless only to claim refund)

CRITICAL: Run software diagnostic
Many preparers face penalties for improper EITC claims
```

**Investment Income Disqualification:**
```
Total investment income must be < $11,000 (2024)

Investment income includes:
- Taxable interest
- Tax-exempt interest
- Dividends
- Capital gain net income
- Royalties
- Rent and passive income

If ≥ $11,000 → NO EITC allowed
```

**Pass Criteria:** All qualifying tests met, due diligence documented, within income limits
**Fail Criteria:** Investment income too high, qualifying tests not met, prior disallowance period

### 4.3 Education Credits (American Opportunity vs Lifetime Learning)
**Decision Tree:**
```
Is student in first 4 years of post-secondary education?
├─ YES → American Opportunity Tax Credit (AOTC)
│   ├─ Credit: 100% of first $2,000 + 25% of next $2,000 = $2,500 max
│   ├─ 40% refundable ($1,000 max refund)
│   ├─ Phase-out: $80k-$90k (Single), $160k-$180k (MFJ)
│   ├─ Student must be degree-seeking, enrolled at least half-time
│   └─ No felony drug conviction
└─ NO → Lifetime Learning Credit (LLC)
    ├─ Credit: 20% of first $10,000 = $2,000 max
    ├─ Non-refundable (cannot exceed tax liability)
    ├─ Phase-out: $80k-$90k (Single), $160k-$180k (MFJ)
    └─ No enrollment requirement, any course of instruction

CANNOT CLAIM BOTH FOR SAME STUDENT IN SAME YEAR
```

**Form 1098-T Verification:**
1. Locate Form 1098-T from educational institution
2. Box 1: Payments received for qualified tuition
3. Verify amounts on Form 8863
4. Qualified expenses: Tuition and required fees (NOT room/board)

**Optimization Check:**
```
If eligible for both credits (multiple students):
- AOTC is usually better (higher credit, partially refundable)
- Use AOTC for first 4 years
- Use LLC for graduate school or continuing education
```

**Pass Criteria:** Proper credit chosen, Form 1098-T matches, phase-out applied
**Fail Criteria:** Both credits for same student, room/board included, phase-out missed

### 4.4 Retirement Savings Contribution Credit (Saver's Credit)
**Often Missed Credit - Check for eligibility:**

**Requirements:**
1. Age 18 or older
2. Not a full-time student
3. Not claimed as dependent on another return
4. Made eligible retirement contribution (IRA, 401k, etc.)

**Credit Calculation:**
```
AGI Ranges (2024):

MFJ:              Credit Rate
$0 - $46,000      50%
$46,001 - $50,000 20%
$50,001 - $76,500 10%
Over $76,500      0%

Single/MFS:
$0 - $23,000      50%
$23,001 - $25,000 20%
$25,001 - $38,250 10%
Over $38,250      0%

HOH:
$0 - $34,500      50%
$34,501 - $37,500 20%
$37,501 - $57,375 10%
Over $57,375      0%

Maximum Credit = $1,000 per person ($2,000 MFJ)
Credit = Contribution × Rate (up to $2,000 contribution)
```

**Pass Criteria:** Eligible taxpayer, contribution verified, correct AGI bracket
**Fail Criteria:** AGI too high, no contribution, full-time student

## Step 5: Tax Calculation and Special Taxes

### 5.1 Alternative Minimum Tax (Form 6251)
**When Form 6251 is Required:**
```
Form 6251 should be completed if:
├─ AGI > $200,000
├─ Itemized deductions include large SALT (state and local tax)
├─ Large miscellaneous itemized deductions (pre-2018)
├─ Exercised incentive stock options (ISOs)
├─ Significant tax-exempt interest from private activity bonds
├─ Large depreciation differences
└─ Passive activity adjustments

Software usually auto-generates, but verify present if conditions exist
```

**AMT Calculation Overview:**
```
1. Start with taxable income
2. Add back AMT adjustments:
   - State and local tax deduction
   - Miscellaneous itemized deductions (pre-2018)
   - Tax-exempt interest from private activity bonds
   - ISO exercise spread
   - Depreciation differences
3. Subtract AMT exemption:
   MFJ: $133,300 (phases out starting at $1,218,700)
   Single: $85,700 (phases out starting at $609,350)
4. Apply AMT rates: 26% and 28%
5. Compare to regular tax
6. Pay the higher amount
```

**Pass Criteria:** Form 6251 present when required, calculation verified
**Fail Criteria:** Form 6251 missing despite high AGI/SALT, AMT underpaid

### 5.2 Net Investment Income Tax (Form 8960)
**Critical Check - Often Missed:**

**Requirement Triggers:**
```
Form 8960 REQUIRED if:

1. MAGI exceeds threshold:
   - Single/HOH: $200,000
   - MFJ: $250,000
   - MFS: $125,000

AND

2. Taxpayer has net investment income
```

**What is Net Investment Income:**
```
INCLUDED:
✓ Interest (taxable and tax-exempt)
✓ Dividends (qualified and ordinary)
✓ Capital gains
✓ Annuity income
✓ Passive activity income (rents, royalties, pass-through)
✓ Income from trading financial instruments

EXCLUDED:
✗ Wages and self-employment income
✗ Operating income from non-passive business
✗ Active rental real estate (if REP status)
✗ Distributions from qualified retirement plans
✗ Social Security benefits
```

**NIIT Calculation:**
```
Step 1: Calculate Modified AGI (MAGI)
MAGI = AGI + Foreign earned income exclusion

Step 2: Calculate threshold excess
Excess = MAGI - Threshold

Step 3: Calculate NIIT
NIIT = 3.8% × LESSER of:
- Net investment income, OR
- Threshold excess

Example: MFJ, AGI $300,000, NII $40,000
Threshold: $250,000
Excess: $300,000 - $250,000 = $50,000
Lesser of $40,000 or $50,000 = $40,000
NIIT = $40,000 × 3.8% = $1,520
```

**Verification Steps:**
1. Calculate MAGI from Form 1040 Line 11
2. Identify all investment income items
3. Verify Form 8960 present if MAGI > threshold
4. Check calculation on Form 8960
5. Verify NIIT flows to Schedule 2 Line 17

**Pass Criteria:** Form 8960 filed when required, calculation correct
**Fail Criteria:** MAGI > threshold with NII but Form 8960 missing, calculation error

### 5.3 Additional Medicare Tax (Form 8959)
**Requirement Triggers:**
```
Wages + Self-Employment Income > Threshold:
- Single/HOH: $200,000
- MFJ: $250,000
- MFS: $125,000

Additional Medicare Tax = 0.9% × Income over threshold
```

**Calculation:**
```
Example: Single, W-2 wages $225,000

Step 1: Identify threshold: $200,000
Step 2: Calculate excess: $225,000 - $200,000 = $25,000
Step 3: Calculate tax: $25,000 × 0.9% = $225

Verify:
- Form 8959 present
- Calculation correct
- Amount flows to Schedule 2 Line 18
```

**Withholding Note:**
- Employer withholds Additional Medicare Tax on wages > $200,000
- But this may be insufficient if MFJ and combined wages > $250,000
- May need estimated tax payments

**Pass Criteria:** Form 8959 filed when required, tax calculated correctly
**Fail Criteria:** Income over threshold but Form 8959 missing

### 5.4 Estimated Tax Penalty (Form 2210)
**When Penalty May Apply:**
```
Tax owed ≥ $1,000 AND insufficient withholding/estimated payments
```

**Safe Harbor Exceptions (NO penalty if meet ANY):**
```
1. Paid ≥ 90% of current year tax liability

2. Paid ≥ 100% of prior year tax liability
   (110% if prior year AGI > $150,000)

3. Owed < $1,000 after withholding and credits

4. Had no tax liability prior year (rare for individuals)

5. Annualized income method (Form 2210 Schedule AI)
   - Used if income uneven throughout year
   - Complex calculation
```

**Verification Procedure:**
```
Step 1: Calculate total tax (Form 1040 Line 24)
Step 2: Subtract payments:
   - Federal withholding (Line 25a)
   - Estimated tax payments (Line 26)
   - Other payments (Line 31)
Step 3: Calculate tax owed (Line 37)

If tax owed ≥ $1,000:
   Check if any safe harbor met
   If no safe harbor → Form 2210 required
   Calculate penalty or document exception
```

**Pass Criteria:** Safe harbor met OR penalty calculated on Form 2210
**Fail Criteria:** Tax owed ≥ $1,000, no safe harbor, Form 2210 missing

## Step 6: State Return Coordination

### 6.1 Federal to State AGI Flow
**Procedure:**
1. Locate federal AGI (Form 1040 Line 11)
2. Locate state return starting line (usually "Federal AGI")
3. Verify amount matches

**Common State Adjustments:**
```
State Additions (Increase state taxable income):
+ Federal tax refund (if itemized prior year)
+ Out-of-state municipal bond interest
+ §179 depreciation addback (some states)
+ NOL deduction (some states don't allow)
+ Federal credits claimed

State Subtractions (Decrease state taxable income):
- State tax refund included in federal income
- In-state municipal bond interest (double-counted)
- Social Security benefits (many states exempt)
- Retirement income (partial exemption in some states)
- Military pay (if stationed in state but not resident)
```

### 6.2 Multi-State Apportionment
**If taxpayer has income from multiple states:**

**Resident State Return:**
- Reports all income (from all sources)
- Claims credit for taxes paid to non-resident states

**Non-Resident State Returns:**
- Reports only income earned in that state
- Calculate apportionment percentage:
  ```
  State Income ÷ Total Income = Apportionment %
  ```

**Verification:**
```
Sum of all state tax liabilities should not exceed federal tax + reasonable state tax
Check for double taxation
Verify resident state credit for taxes paid to non-resident states
```

### 6.3 State-Specific Items
**Check for Common State Issues:**

**California:**
- Higher tax rates
- Does not conform to many federal provisions
- Form 540 or 540NR
- Alternative minimum tax at state level

**New York:**
- NYC residents pay city tax in addition to state
- Yonkers residents pay separate Yonkers tax
- Non-resident forms if commute from other states

**Texas:**
- No state income tax
- But check for franchise tax if business entity

**Florida:**
- No state income tax
- But check for intangibles tax (rare)

**Pass Criteria:** State AGI ties to federal, adjustments proper, all required states filed
**Fail Criteria:** AGI mismatch, missing state returns, no credit for taxes paid to other states

**Pass Criteria:** High-risk items documented and supported
**Fail Criteria:** Multiple red flags without documentation

### 7.2 Common Error Final Check
**Final Sweep - These Are Most Common Errors:**

**K-1 Related:**
- [ ] Box 1 ordinary income placed on Schedule C (WRONG - should be Schedule E)
- [ ] Passive losses from K-1 claimed without Form 8582
- [ ] Basis limitations not applied to K-1 losses
- [ ] Self-rental rule not applied

**Missing Forms:**

**Pass Criteria:** All common errors reviewed and none present
