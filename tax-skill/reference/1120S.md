# Form 1120S Review Workflow

## Step 1: S Corporation Status Verification

### 1.1 Verify Valid S Election
**Procedure:**
1. Confirm Form 2553 (S Corporation Election) on file
2. Check effective date of S election - must have been timely filed:
   - Within 2 months and 15 days of start of tax year for which effective, OR
   - Any time during prior tax year
3. If first year as S Corp, verify Form 2553 in files with IRS acceptance
4. All shareholders must have consented on Form 2553

**Late Election Relief:**
```
If Form 2553 filed late but should qualify:
Check if eligible for relief under Rev. Proc. 2013-30:
- Intended to be S Corp
- Failed to qualify solely due to late filing
- Reasonable cause exists
- Less than 3 years 75 days from intended effective date

If applicable, file relief request with reasonable cause statement
```

**Pass Criteria:** Form 2553 on file, timely filed, all shareholders consented
**Fail Criteria:** No Form 2553, late filing without relief, missing shareholder consents

### 1.2 Check for Terminating Events
**S Election Terminates If:**

**1. Too Many Shareholders:**
```
Maximum: 100 shareholders

Family counting rules:
- Family members count as ONE shareholder
- Family = common ancestor + lineal descendants + spouses
- 6-generation limit

Verify shareholder count ≤ 100 after family grouping
```

**2. Ineligible Shareholder:**
```
ELIGIBLE shareholders only:
✓ U.S. citizens or residents (individuals)
✓ Estates
✓ Certain trusts (QSST, ESBT, grantor trusts)
✓ 501(c)(3) tax-exempt organizations

INELIGIBLE (causes termination):
✗ Partnerships
✗ Corporations (except qualified Subchapter S subsidiaries)
✗ Non-resident aliens
✗ Most trusts (testamentary ok for 2 years)
```

**3. Second Class of Stock:**
```
Only ONE class of stock permitted

What causes second class:
✗ Different distribution rights
✗ Different liquidation rights
✗ Debt reclassified as equity with participation features

What's OK:
✓ Voting vs non-voting shares (distribution rights same)
✓ Straight debt (specific requirements)
✓ Proportionate distributions
```

**4. Excess Passive Investment Income (if E&P exists):**
```
If S Corp has C Corp E&P AND
Passive investment income > 25% of gross receipts
For 3 consecutive years
→ S election terminates

Only applies to former C Corps with accumulated E&P
```

**Pass Criteria:** No terminating events occurred, S status maintained all year
**Fail Criteria:** Terminating event occurred, invalid S Corp

### 1.3 One Class of Stock Verification
**Detailed Analysis Required - Common IRS Challenge:**

**Safe Harbor - Distributions:**
```
Distributions must be pro-rata per share ownership

Example - CORRECT:
Shareholder A: 60 shares (60%)
Shareholder B: 40 shares (40%)
Distribution: $100,000
A receives: $60,000 (60%)
B receives: $40,000 (40%)  ✓ Pro-rata

Example - WRONG:
Same ownership, but:
A receives: $70,000 (70%)
B receives: $30,000 (30%)  ✗ Not pro-rata
This creates second class of stock!
```

**Debt vs Equity Analysis:**
```
Is shareholder loan actually equity?

Factors indicating DEBT (safe):
✓ Fixed maturity date
✓ Stated interest rate
✓ Written promissory note
✓ Timely interest/principal payments
✓ Debt appears on balance sheet
✓ Corp has debt-equity ratio <3:1

Factors indicating EQUITY (problem):
✗ No maturity date or very distant
✗ Interest dependent on profits
✗ Subordinated to other creditors
✗ No payments made
✗ Advances treated as capital contributions
```

**Disproportionate Distributions:**
```
Timing matters:
All distributions in same tax year must be pro-rata

NOT a violation:
- Distribution to A in January
- Distribution to B in December
- Both pro-rata to their ownership %

IS a violation:
- Different per-share amounts
- Some shareholders skipped
- Distributions based on different rights
```

**Pass Criteria:** Only one class, distributions pro-rata, debt properly classified
**Fail Criteria:** Disproportionate distributions, debt reclassified as equity, different rights

## Step 2: Book-Tax Reconciliation

### 2.1 Schedule M-1 Review
**The Critical Reconciliation:**

```
Schedule M-1 Flow:
Line 1: Net income per books (from P&L)
Lines 2-3: Add: Income on books not on return + Expenses not deductible
Line 4: Subtotal
Line 5: Income on return not on books
Line 6: Deductions on return not on books
Line 7: Subtotal (Lines 4-5-6)
Line 8: Taxable income before NOL/special deductions
    (Should tie to Schedule K Line 1 + separately stated items)
```

**Common Book-Tax Differences:**

**Lines 2-3 (ADD to book income):**
```
1. Federal income tax expense (Line 2b)
   - S Corps don't pay entity-level tax (usually)
   - But may have built-in gains tax, excess net passive income tax
   - Added back because not deductible

2. Excess capital losses (Line 2c)
   - Capital losses > capital gains
   - Not deductible at entity level
   - Carry forward as capital loss

3. Meals & Entertainment (Line 3, part)
   - 50% not deductible (booked 100%, deduct 50%)
   - Example: $10,000 meals on books
              Add back $5,000 (50% limitation)

4. Depreciation (if book > tax) (Line 3, part)
   - Book depreciation $50,000
   - Tax depreciation $80,000 (bonus depreciation)
   - ADD here: $0 (or subtract on Line 6 - see below)

5. Charitable contributions (Line 3, part)
   - Separately stated on K-1 Box 13
   - Not deducted in ordinary income
   - Add back full amount

6. §179 expense deduction (Line 3, part)
   - Separately stated on K-1 Box 13
   - Not deducted in ordinary income
   - Add back full amount

7. Non-deductible expenses (Line 3, part)
   - Penalties and fines
   - Political contributions
   - Life insurance premiums (if S Corp is beneficiary)
   - 50% of meals (see above)
```

**Lines 5-6 (DEDUCT from taxable income):**
```
1. Tax-exempt interest (Line 5a)
   - Municipal bond interest
   - Included in ordinary income for tax (Line 5)
   - But not taxable, so deduct

2. Depreciation (if tax > book) (Line 6a)
   - Book depreciation $50,000
   - Tax depreciation $80,000 (bonus depreciation)
   - Subtract $30,000 difference
```

**Verification Steps:**
1. Obtain S Corp's P&L from QuickBooks/books
2. Identify book net income
3. Verify Line 1 = book net income
4. For each adjustment Lines 2-6:
   - Verify amount is reasonable
   - Trace to source (tax return, books, detail schedule)
5. Calculate Schedule M-1 Line 7
6. Verify Line 8 = Schedule K Line 1 (ordinary income) + separately stated deductions

**Pass Criteria:** Schedule M-1 balances, all adjustments reasonable and supported
**Fail Criteria:** Doesn't balance, missing adjustments, unsupported amounts

### 2.2 Schedule M-2 - AAA Account (CRITICAL FOR S CORPS)
**Accumulated Adjustments Account - Tracks Tax-Free Distribution Capacity:**

**AAA Concept:**
```
AAA = Accumulated earnings since becoming S Corp that have been taxed
      to shareholders but not yet distributed

Purpose: Determines which distributions are tax-free to shareholders

If distribution ≤ AAA → Tax-free (return of basis)
If distribution > AAA → May be taxable dividend (if E&P exists)
```

**AAA Calculation:**
```
Line 1: Beginning AAA (from prior year Line 8)

ADD (Lines 2-3):
+ Ordinary income (from Schedule K Line 1)
+ Separately stated income/gains (Schedule K Lines 2-6, 9-10)
+ Nonseparately stated income
+ Deductions for depletion (oil/gas only)

NOTE: Do NOT add tax-exempt income (goes to OAA instead)

SUBTRACT (Lines 4-5):
- Distributions (Line 4) (limited to available AAA)
- Loss/deductions from Schedule K
- Nonseparately stated losses/deductions
- Expense of producing tax-exempt income (nondeductible)

Line 6: Net AAA before distributions
Line 7: Distributions from AAA (lesser of Line 4 or Line 6)
Line 8: Ending AAA
```

**Critical AAA Rules:**

**1. AAA Can Go Negative from Losses (but not distributions):**
```
Example 1 - Losses:
Beginning AAA: $10,000
Current loss: ($30,000)
Ending AAA: ($20,000)  ✓ ALLOWED

Example 2 - Distributions:
Beginning AAA: $10,000
Distributions: $30,000
Ending AAA: $0  ← Stops at zero, not negative
Excess $20,000 goes through E&P/basis rules
```

**2. Distribution Ordering (if distributions > AAA):**
```
Step 1: Reduce AAA to zero (tax-free to extent of stock basis)
Step 2: Reduce PTI if any (pre-1983 S Corp) (tax-free)
Step 3: Reduce E&P if any (taxable dividend)
Step 4: Reduce stock basis (tax-free)
Step 5: Excess over basis = capital gain
```

**3. Ordering of Adjustments:**
```
Proper order within tax year:
1. Add income items
2. Subtract losses/deductions (can go negative)
3. Subtract distributions (cannot go negative)

This ordering matters when AAA is low/negative
```

**Other Adjustments Account (OAA) - Column (c):**
```
Tracks tax-exempt income and related expenses

Line 1: Beginning OAA
Line 2: Tax-exempt interest income
Line 3: Nondeductible expenses related to tax-exempt income
Lines 4-6: Distributions from OAA (after AAA depleted)
Line 8: Ending OAA
```

**Accumulated E&P - Column (d):**
```
Only applies if S Corp was formerly a C Corp

C Corp accumulated E&P carries forward
Reduced by distributions after AAA is depleted
Distributions from E&P = taxable dividends to shareholders

If E&P exists:
- Monitor for excess passive income rules
- Track carefully for distribution ordering
```

**Previously Taxed Income (PTI) - Column (e):**
```
Only applies to pre-1983 S Corps (very rare now)

Income taxed to shareholders before AAA rules
Distributions from PTI are tax-free

Most S Corps formed after 1982 will have $0 here
```

**Verification Steps:**
1. Verify beginning AAA ties to prior year ending AAA
2. Check ordinary income (Line 2) = Schedule K Line 1
3. Verify separately stated items added (income) or subtracted (deductions)
4. Confirm tax-exempt income NOT in AAA (should be in OAA)
5. Verify distributions don't reduce AAA below zero
6. Calculate ending AAA
7. Verify ending AAA reasonable (shouldn't be hugely negative)

**Common Errors:**
- Tax-exempt income added to AAA (goes to OAA)
- Distributions reducing AAA below zero
- Forgetting to subtract separately stated deductions
- Prior year mismatch

**Pass Criteria:** AAA properly calculated, ties to prior year, distributions handled correctly
**Fail Criteria:** AAA calculation wrong, goes negative from distributions, prior year mismatch

### 2.3 Schedule L - Balance Sheet
**Must Balance and Tie:**

```
ASSETS = LIABILITIES + EQUITY

Line 14 (Total assets) must equal Line 23 (Total liabilities + equity)
```

**Critical Tie-Outs:**
1. **Retained Earnings (Line 23)** must tie to Schedule M-2 Column (a) Line 8 (ending AAA) [if no E&P]
   OR sum of AAA + OAA + E&P [if E&P exists]

2. **Beginning balance sheet** should tie to **prior year ending balance sheet**

**Shareholder Loans:**
```
Loans TO corporation from shareholders (liability):
- Schedule L Line 18 or 19
- Interest paid at reasonable rate?
- Is it really debt or equity? (see Step 1.3)

Loans FROM corporation to shareholders (asset):
- Schedule L Line 7
- Interest charged at AFR (Applicable Federal Rate)?
- Below-market loans = imputed interest + compensation
- Large loans may indicate distribution vs loan
```

**Pass Criteria:** Balance sheet balances, ties to M-2, reasonable tie to prior year
**Fail Criteria:** Doesn't balance, M-2 tie-out wrong, no continuity from prior year

## Step 3: Reasonable Compensation Analysis (MOST CRITICAL!)

### 3.1 Why Reasonable Compensation Matters
**#1 IRS Audit Issue for S Corporations:**

```
THE PROBLEM:
S Corp shareholder-employee pays:
- Payroll taxes (15.3%) on W-2 wages
- NO payroll taxes on distributions

TEMPTATION:
Pay low wages, take high distributions
Save payroll taxes!

IRS RESPONSE:
Recharacterize distributions as wages
Assess payroll taxes + penalties + interest
```

**Tax Difference Example:**
```
Scenario 1: All wages
Wages: $100,000
Payroll tax: $15,300
Income tax on $100,000: $18,000
Total tax: $33,300

Scenario 2: Low wage, high distribution (RISKY)
Wages: $30,000
Distribution: $70,000
Payroll tax: $4,590
Income tax on $100,000: $18,000 (same)
Total tax: $22,590
Savings: $10,710

But... if IRS recharacterizes, taxpayer owes:
Back payroll taxes: $10,710
Penalties: ~$2,000
Interest: ~$1,500
TOTAL EXPOSURE: ~$14,000+
```

### 3.2 Reasonable Compensation Factors
**IRS Uses Multi-Factor Test:**

**1. Training and Experience:**
```
More experienced → Higher compensation expected

Questions:
- Education level?
- Professional certifications?
- Years in industry?
- Specialized knowledge?
```

**2. Duties and Responsibilities:**
```
What does shareholder-employee actually do?

- CEO/President: Full management duties → Higher comp
- Key employee: Critical to operations → Higher comp
- Minimal involvement: Part-time work → Lower comp justified
```

**3. Time and Effort Devoted:**
```
Full-time (40+ hours/week) → Full-time compensation
Part-time (20 hours/week) → Proportionate compensation
```

**4. Dividend History:**
```
Consistent distributions but low wages → Red flag
IRS argues distributions are really wages
```

**5. Payments to Non-Shareholder Employees:**
```
Non-shareholder doing similar work paid $80,000
Shareholder doing same work paid $35,000
→ Big problem! Should be comparable
```

**6. Timing and Manner of Payments:**
```
Monthly salary → Looks like wages
Irregular large payments → Looks like distributions
```

**7. Comparison to Industry:**
```
Use compensation databases:
- Bureau of Labor Statistics (BLS)
- RMA Annual Statement Studies
- Salary.com, PayScale.com
- Industry trade associations

If shareholder comp significantly below industry average:
Document reasons or increase wages
```

**8. Payments to Shareholders Compared to Non-Shareholder Employees:**
```
Non-shareholder manager: $75,000
Shareholder-employee doing more: $40,000
→ Not reasonable
```

**9. Company's Financial Condition:**
```
Profitable company → Can afford reasonable compensation
Consistent losses → May justify lower compensation
But can't pay zero if shareholder working!
```

### 3.3 Reasonable Compensation Safe Harbors
**While no official safe harbor, consider these guidelines:**

**Rule of Thumb Approaches:**

**1. 60/40 Rule:**
```
Reasonable Compensation ≥ 40% of S Corp net income (before officer comp)

Example:
S Corp net income before officer comp: $200,000
Minimum suggested wage: $80,000 (40%)
Distribution: $120,000 (60%)

This is NOT a legal safe harbor but widely used
```

**2. Market-Based Approach:**
```
Pay what comparable employee would earn in marketplace

Use BLS data for occupation + location:
- Occupation code
- Metropolitan area
- 75th percentile wage (conservative)

Example:
Accountant, Cleveland, OH
BLS 75th percentile: $85,000
Pay at least $85,000 to shareholder-CPA
```

**3. Multiple Approaches (Best Practice):**
```
Calculate under multiple methods, use highest:

Method 1 - 40% rule: $80,000
Method 2 - BLS market rate: $85,000
Method 3 - Employee comparison: $75,000
Method 4 - Investor return: $90,000

Choose: $90,000 (most conservative)
```

### 3.4 Verification Procedure
**For Form 1120S Review:**

**Step 1: Identify Officer-Shareholders:**
```
List all shareholders who are also employees:
- Name
- Ownership %
- Role in company
- Typical hours worked
```

**Step 2: Verify W-2 Issued:**
```
For EACH shareholder-employee:
- W-2 must be issued
- Box 1 (wages) > $0
- Boxes 3 & 5 (FICA) show wages and withholding
- Verify Form 941 filed quarterly
```

**Step 3: Compare Wages to Distributions:**
```
Shareholder A:
W-2 wages (Line 7): $45,000
K-1 distributions (K-1 Line 16): $150,000
Ratio: 23% wages, 77% distributions  ⚠ RED FLAG

S Corp net income: $200,000
Officer comp %: 22.5%  ⚠ Too low!
```

**Step 4: Apply Reasonableness Tests:**
```
Test 1: 40% Rule
Net income before comp: $200,000
40% = $80,000
Actual comp: $45,000  ✗ FAILS

Test 2: BLS Comparison
Similar position, same location: $75,000
Actual comp: $45,000  ✗ FAILS

Test 3: Employee Comparison
Other employees similar role: $70,000
Actual comp: $45,000  ✗ FAILS

CONCLUSION: Compensation likely unreasonably low
```

**Step 5: Document Analysis:**
```
Create workpaper documenting:
- Compensation determination methodology
- Comparability data used
- Rationale for compensation level
- Risk assessment

If compensation appears low:
- Flag for revision
- Calculate recommended minimum
- Document potential IRS exposure
```

**Red Flag Thresholds:**
```
✓ PROBABLY OK:
- Officer comp > 50% of net income
- Wages comparable to market rates
- Similar to non-shareholder employees

⚠ REVIEW NEEDED:
- Officer comp 30-50% of net income
- Wages somewhat below market
- Needs documentation

🔴 HIGH RISK:
- Officer comp < 30% of net income
- Wages significantly below market (<$50k for full-time profitable S Corp)
- Distributions 3x or more of wages
- No wages despite shareholder working full-time
```

**Pass Criteria:** Wages reasonable and documented, comparable to market, W-2s issued
**Fail Criteria:** Wages suspiciously low, no W-2 for working shareholder, lack of documentation

## Step 4: 2% Shareholder Special Rules

### 4.1 Health Insurance Premiums
**Special Treatment Required:**

**The Rule:**
```
2% shareholder = anyone owning >2% of stock (directly or by attribution)

Health insurance premiums for 2% shareholder:
1. MUST be included in W-2 Box 1 (wages)
2. But NOT in Boxes 3 or 5 (no FICA/Medicare tax)
3. Deducted by S Corp as fringe benefit
4. Shareholder claims above-the-line deduction on Form 1040 Schedule 1
```

**Step-by-Step Treatment:**

**Step 1: S Corp Pays Premiums:**
```
S Corp pays health insurance: $12,000/year
Records as compensation/fringe benefit expense
Deducts on Form 1120S (usually Line 19, other deductions)
```

**Step 2: Include in W-2:**
```
W-2 Box 1: $60,000 (wages) + $12,000 (health ins) = $72,000
W-2 Box 3: $60,000 (FICA wages - does NOT include health ins)
W-2 Box 5: $60,000 (Medicare wages - does NOT include health ins)

Box 14 or separate statement: "Health insurance $12,000" (informational)
```

**Step 3: Shareholder's 1040:**
```
Form 1040:
Line 1: W-2 income $72,000 (includes health ins)

Schedule 1 Line 17: Self-employed health insurance deduction $12,000
(Even though not technically self-employed)

Net effect: Health insurance is deductible, not taxed
```

**Verification Steps:**
1. Identify all 2% shareholders
2. Determine if S Corp paid health insurance for any
3. For each 2% shareholder with health insurance:
   ```
   Premium amount: $_______
   In W-2 Box 1? YES / NO
   NOT in W-2 Boxes 3 & 5? YES / NO
   Deducted by S Corp? YES / NO
   ```
4. If health insurance NOT in Box 1 → ERROR, must correct with W-2c

**Limitation:**
```
Shareholder's deduction cannot exceed:
- S Corp wages (Box 1 less health insurance), OR
- Self-employment income from other sources

Example:
W-2 wages (before health ins): $20,000
Health insurance: $12,000
W-2 Box 1 total: $32,000

Shareholder's deduction limited to: $20,000 wages
Can only deduct $12,000 if wages ≥ $12,000
```

**Common Mistakes:**
```
✗ WRONG: Health insurance not in W-2 Box 1
✗ WRONG: Health insurance in Boxes 3 & 5 (causes payroll tax)
✗ WRONG: S Corp doesn't deduct (loses deduction)
✗ WRONG: Shareholder claims on Schedule A (should be Schedule 1)

✓ CORRECT: In Box 1, not in Boxes 3/5, S Corp deducts, shareholder claims Schedule 1
```

**Pass Criteria:** Health insurance properly in W-2 Box 1, not in Boxes 3/5, S Corp deducted
**Fail Criteria:** Missing from Box 1, in Boxes 3/5, not deducted, exceeds wages

### 4.2 Other Fringe Benefits
**2% Shareholders Cannot Exclude:**

**Fringe Benefits Taxable to 2% Shareholders:**
```
✗ Group-term life insurance (>$50,000 coverage) - Taxable
✗ Section 125 cafeteria plans - Cannot participate
✗ Dependent care assistance - Taxable
✗ Achievement awards - Taxable (over $400)
✗ Adoption assistance - Taxable
✗ Educational assistance - Taxable (over $5,250)

If provided to 2% shareholder:
→ Must be included in W-2 wages (Box 1)
→ Subject to income tax
```

**Fringe Benefits Still Available:**
```
✓ Retirement plans (401k, SEP, SIMPLE) - Still available
✓ Accountable expense reimbursements - Not taxable if meet requirements
✓ De minimis benefits - Still excluded
```

**Pass Criteria:** Fringe benefits for 2% shareholders properly included in wages
**Fail Criteria:** Impermissible exclusions, cafeteria plan participation

## Step 5: Income, Deductions, and Separately Stated Items

### 5.1 Ordinary Business Income Calculation
**Follows Same Logic as C Corporation:**

**Key Lines Review:**

**Line 1a - Gross Receipts/Sales:**
- Compare to prior year
- Check for Form 1099-K
- Verify tie to books/sales journal

**Line 2 - Cost of Goods Sold:**
- Form 1125-A required if inventory
- Beginning inventory ties to prior year ending
- Ending inventory ties to Schedule L Line 3
- Gross profit margin reasonable for industry

**Line 7 - Compensation of Officers:**
```
CRITICAL LINE:
Sum of all W-2 wages to officer-shareholders

Must tie to:
- W-2s issued to officers
- Box 1 of each officer's W-2

Common error: Forgetting to include 2% shareholder health insurance
Remember: Health ins in Box 1, but also deducted elsewhere
```

**Line 12 - Taxes and Licenses:**
```
Includes:
✓ State and local business taxes
✓ Payroll taxes (employer portion)
✓ Business licenses
✓ Property taxes on business assets

Does NOT include:
✗ Federal income tax (not applicable to S Corp except built-in gains tax)
✗ Shareholder personal taxes
✗ Sales tax collected and remitted (already excluded from income)
```

**Line 18 - Pension, Profit-Sharing Plans:**
```
Employer contributions to:
- 401(k) plans
- SEP IRAs
- SIMPLE IRAs
- Defined benefit plans

Must be for common-law employees (including 2% shareholders)
Verify doesn't exceed contribution limits
```

**Line 19 - Employee Benefit Programs:**
```
Health insurance premiums (non-2% shareholders)
Group-term life insurance
Other fringe benefits

2% shareholder health insurance:
- Still deducted here (or other line)
- But must be in W-2 Box 1
```

**Line 20 - Other Deductions:**
```
Attach statement detailing:
- Professional fees
- Advertising
- Office expenses
- Etc.

Check for non-deductible items:
✗ Penalties and fines
✗ Political contributions
✗ 50% of meals and entertainment
```

### 5.2 Separately Stated Items (Schedule K)
**Must Be Separated Because Shareholders Have Different Tax Treatment:**

**Line 2 - Net Rental Real Estate Income/Loss:**
```
Why separately stated:
- May be passive to shareholder
- Subject to at-risk rules
- Real estate professional status

Verify:
✓ Supported by rental property schedule
✓ Depreciation, mortgage interest included
✓ Passive activity designation on K-1
```

**Line 3 - Other Net Rental Income/Loss:**
```
Equipment rentals, personal property rentals
Different passive activity rules than real estate
```

**Lines 4-5 - Interest and Dividends:**
```
Investment income, separately stated for:
- Net investment income tax (Form 8960) at shareholder level
- Investment interest expense limitation

Line 4a: Interest income
Line 5a: Ordinary dividends
Line 5b: Qualified dividends (preferential rate)
```

**Lines 7-8 - Capital Gains and §1231 Gains:**
```
Taxed at preferential rates at shareholder level

Line 7: Net short-term capital gain/loss
Line 8: Net long-term capital gain/loss

Verify:
✓ Form 8949 and Schedule D attached
✓ Basis calculations correct
✓ Holding periods properly classified
```

**Line 9 - Other Income/Loss:**
```
Catch-all for items not fitting elsewhere:
- §481 adjustments
- Cancellation of debt income
- Gambling income
- Recoveries

Attach statement with details
```

**Lines 11-12 - Other Deductions:**
```
Line 12 code A: Cash contributions (60% limitation)
Line 12 code B: Non-cash contributions (30% limitation)
Line 12 code C: §179 deduction

WHY SEPARATELY STATED:
Shareholders subject to individual limitations:
- Charitable: % of shareholder's AGI
- §179: $1,220,000 max, limited to shareholder's taxable income
```

**Line 13 - Credits:**
```
Various credits with codes:
A: Low-income housing
B: Rehabilitation credit
C: Energy credit
D-P: Other credits

Flow through to shareholder's return
Subject to shareholder limitations and phase-outs
```

**Pass Criteria:** All separately stated items identified and properly allocated to K-1s
**Fail Criteria:** Items included in ordinary income that should be separate, missing support

## Step 6: Shareholder Basis and K-1 Review

### 6.1 Shareholder Stock Basis Calculation
**Critical for Loss Limitations and Distribution Taxation:**

```
SHAREHOLDER STOCK BASIS:

Beginning Basis (from prior year)
+ Additional stock purchases
+ Capital contributions
+ Share of income items (all types including tax-exempt)
- Distributions (non-dividend)
- Share of non-deductible expenses
- Share of losses and deductions
= Ending Stock Basis (cannot go below zero)

STOCK BASIS CANNOT BE NEGATIVE
If losses exceed basis → Losses suspended
```

**Basis Increases:**
```
1. Share of ordinary income (K-1 Box 1)
2. Separately stated income items (K-1 Boxes 2-6)
3. Tax-exempt income (even though not taxable)
4. Capital contributions
5. Additional stock purchases
```

**Basis Decreases (Applied in This Order):**
```
Order matters!

1. Distributions (cash and property FMV) - K-1 Box 16
2. Non-deductible expenses (K-1 Box 16)
3. Depletion (to extent of basis in property)
4. Loss and deduction items - K-1 Boxes 1-3, 11-12

Stock basis reduced in this order
Cannot go below zero
```

**Debt Basis (Separate from Stock Basis):**
```
Only applies if shareholder loans money DIRECTLY to S Corp

Creates debt basis:
✓ Direct loan from shareholder to S Corp (promissory note)
✓ Shareholder advances funds to S Corp

Does NOT create debt basis:
✗ Shareholder guarantees bank loan (no basis increase)
✗ Shareholder pledges assets as collateral (no basis increase)
✗ Back-to-back loan arrangements (no basis increase)

If shareholder has debt basis:
- Losses reduce stock basis first, then debt basis
- Distributions do NOT reduce debt basis
- Debt repayment reduces debt basis (but may restore stock basis)
```

**Loss Limitation:**
```
If shareholder's share of losses > available basis:

Step 1: Calculate available basis
Stock basis: $20,000
Debt basis: $10,000
Total available: $30,000

Step 2: Compare to losses
K-1 Box 1 loss: ($40,000)

Step 3: Limit losses
Allowable loss: $30,000 (limited to basis)
Suspended loss: $10,000 (carried forward indefinitely)

Step 4: Reduce basis
Stock basis: $0 (reduced by $20,000)
Debt basis: $0 (reduced by $10,000)
Ending basis: $0

Suspended loss $10,000 carries forward
Can be used when basis increases in future
```

**At-Risk Limitation (In Addition to Basis):**
```
Even if shareholder has basis, losses limited to at-risk amount

At-risk amount generally equals:
Basis - Nonrecourse debt
(But qualified nonrecourse real estate financing allowed)

If loss exceeds at-risk amount:
Form 6198 required
Excess loss suspended separately from basis limitation
```

### 6.2 Distribution Taxation
**Treatment Depends on AAA, E&P, and Basis:**

**Distribution Ordering Rules:**

**Scenario 1: S Corp with AAA but no E&P (Most Common):**
```
Step 1: Distributions reduce AAA to zero
- Tax-free to extent of stock basis
- Reduces stock basis

Step 2: Distributions in excess of AAA
- Tax-free to extent of remaining stock basis
- Reduces stock basis to zero

Step 3: Distributions in excess of basis
- Taxed as capital gain
- No further basis reduction (already at zero)

Example:
AAA: $50,000
Shareholder basis: $80,000
Distribution: $100,000

Analysis:
$50,000: Reduces AAA to zero, tax-free, basis now $30,000
$30,000: Reduces basis to zero, tax-free
$20,000: Taxed as capital gain (15% or 20% rate usually)
```

**Scenario 2: S Corp with E&P (Former C Corp):**
```
More complex ordering:

Step 1: Reduce AAA (tax-free to extent of basis)
Step 2: Reduce PTI if any (tax-free)
Step 3: Reduce E&P (TAXABLE DIVIDEND - ordinary income rates!)
Step 4: Reduce remaining basis (tax-free)
Step 5: Excess = capital gain

This ordering is critical!
Distributions from E&P are TAXABLE DIVIDENDS, not capital gains
```

**Election to Distribute E&P First:**
```
S Corp can elect to distribute E&P before AAA
Requires consent of all shareholders
Allows cleaning out E&P to avoid future dividend treatment
```

**Verification Procedure:**
1. Identify total distributions from Schedule M-2 Line 7
2. For EACH shareholder:
   ```
   K-1 Box 16: Cash distribution $______
   K-1 Box 16: Property distribution FMV $______
   Total distributions: $______
   ```
3. Verify sum of all K-1 distributions = Schedule M-2 Line 7
4. Determine distribution treatment:
   ```
   AAA available: $______
   E&P: $______ (if former C Corp)
   Shareholder basis before distribution: $______
   
   Tax-free portion: $______
   Dividend portion: $______ (if E&P exists)
   Capital gain portion: $______
   ```
5. If distribution exceeds AAA + basis → Flag for shareholder reporting

**Pass Criteria:** Distributions properly reported on K-1s, ordering rules applied, taxation determined
**Fail Criteria:** Distributions exceed AAA without basis analysis, E&P ordering wrong

## Step 7: Built-In Gains Tax (Former C Corps)

### 7.1 Built-In Gains Tax Overview
**Only Applies to S Corps That Were Formerly C Corps:**

**The Rule:**
```
If S Corp was C Corp and elected S status:
- Assets at conversion may have built-in appreciation
- If sold within 5 years, gain subject to entity-level tax
- This is exception to normal S Corp pass-through taxation

Recognition period: 5 years from S election effective date
```

**Example:**
```
Company was C Corp, elected S effective January 1, 2023

At conversion date:
Asset basis: $100,000
Fair market value: $200,000
Built-in gain: $100,000

In 2024 (within 5-year period), sells asset for $250,000:
Total gain: $150,000
Built-in gain (subject to BIG tax): $100,000
Post-conversion gain (regular S Corp treatment): $50,000

Built-in gains tax:
$100,000 × 21% = $21,000 (paid by S Corp at entity level)
$150,000 - $21,000 = $129,000 flows through to shareholders
```

### 7.2 Verification Procedure
**If S Corp was formerly C Corp:**

```
Step 1: Determine S election effective date
From Form 2553: ____________

Step 2: Calculate years since S election
Current year: 2024
S election effective: 2020
Years elapsed: 4 years  ← Still within 5-year recognition period

Step 3: Review asset sales during year
Did S Corp sell any assets that existed at conversion?
YES / NO

If YES:
Step 4: Calculate built-in gain
Asset basis at conversion: $______
FMV at conversion: $______
Built-in gain: $______ (FMV - Basis)

Selling price: $______
Total gain: $______ (Selling price - Basis)

Built-in gain recognized (lesser of built-in or total): $______

Step 5: Calculate built-in gains tax
Built-in gain recognized: $______
× Tax rate: 21%
= Built-in gains tax: $______

Step 6: Verify tax reported
Form 1120S Schedule D, Line 20: Built-in gains tax $______
Flows to Form 1120S Line 22c
Also flows to Schedule K Line 16b (to shareholders)
```

**Pass Criteria:** BIG tax calculated if applicable, proper recognition period applied, tax reported on return
**Fail Criteria:** Former C Corp within 5 years, asset sale, BIG tax not calculated

## Step 8: State Compliance

### 8.1 State S Election Verification
**Federal S Election Does NOT Automatically Apply to States:**

**States That Require Separate S Election:**
```
These states do NOT automatically recognize federal S election:

- California: Form 100S required
- Connecticut: State S election required
- DC: Form D-20S, separate election
- Louisiana: CIFT-620, separate election
- New Hampshire: Business profits tax, separate election
- New Jersey: Separate election required
- New York: Separate election required (within 30 days of federal)
- Tennessee: Franchise & excise tax, separate election
- Texas: Franchise tax (no S election)
```

**States With Automatic Recognition:**
```
Most other states automatically recognize federal S election
But verify for each state where corp does business
```

**Verification Procedure:**
1. Identify all states where S Corp does business
2. For each state, determine:
   ```
   State: ____________
   Recognizes federal S election automatically? YES / NO
   If NO, separate state S election filed? YES / NO / UNKNOWN
   If not filed, flag for correction
   ```

**Pass Criteria:** All required state S elections filed
**Fail Criteria:** Operating in state requiring separate election but not filed

## Step 9: Quality Control & Common Errors

### 9.1 S Corporation-Specific Error Checklist
**Most Common S Corp Errors:**

**1. Reasonable Compensation Issues:**
```
- [ ] Officer compensation < $50,000 for profitable S Corp?
- [ ] Distributions > 3x wages?
- [ ] No W-2 issued despite shareholder working?
- [ ] Compensation not comparable to market?

If ANY YES → Flag for review and correction
```

**2. AAA Account Errors:**
```
- [ ] AAA went negative from distributions? (only losses can make negative)
- [ ] Tax-exempt income in AAA? (should be in OAA)
- [ ] AAA doesn't tie to prior year?
- [ ] Distributions not reducing AAA?
```

**3. 2% Shareholder Health Insurance:**
```
- [ ] Health insurance NOT in W-2 Box 1?
- [ ] Health insurance in W-2 Boxes 3 and/5? (should NOT be)
- [ ] S Corp didn't deduct health insurance?
- [ ] Shareholder claimed on Schedule A instead of Schedule 1?
```

**4. Basis Limitations:**
```
- [ ] Losses claimed exceed shareholder basis without suspension?
- [ ] Basis tracking worksheet missing?
- [ ] Debt basis claimed for guaranteed loans (must be direct loan)?
- [ ] Distributions exceed basis without capital gain reported?
```

**5. One Class of Stock:**
```
- [ ] Disproportionate distributions?
- [ ] Different rights among shareholders?
- [ ] Debt reclassified as equity?
```

**6. Separately Stated Items:**
```
- [ ] Charitable contributions included in ordinary income? (should be separate)
- [ ] §179 deduction included in ordinary income? (should be separate)
- [ ] Sum of K-1s ≠ Schedule K for any line?
```

**7. Built-In Gains Tax:**
```
- [ ] Former C Corp within 5 years?
- [ ] Asset sales occurred?
- [ ] BIG tax not calculated?
```

**8. State Compliance:**
```
- [ ] State S election not filed where required?
- [ ] Nonresident shareholder withholding not remitted?
- [ ] Missing state returns despite nexus?
```

**Pass Criteria:** None of common errors present
**Fail Criteria:** Any common error found

### 9.2 Mathematical Verification
**Cross-Check All Tie-Outs:**

```
Schedule K (Corp-level) totals:
↓
Must equal sum of all K-1s for each line
↓
Example:
Schedule K Line 1: $200,000
K-1s: $120,000 + $50,000 + $30,000 = $200,000  ✓

Verify for EVERY line (Lines 1-20)
```

**Schedule M-2 to Schedule L:**
```
Schedule M-2 Column (a) Line 8 (Ending AAA)
Should approximate
Schedule L Line 23 (Retained earnings)

(May differ if E&P or OAA exists)
```

**Officer Compensation:**
```
Form 1120S Line 7: Officer compensation $______
Must equal
Sum of all officer W-2s Box 1 amounts: $______

If ≠ → Error in reporting
```

**Pass Criteria:** All tie-outs verified, mathematically accurate
**Fail Criteria:** Tie-out failures, summation errors
