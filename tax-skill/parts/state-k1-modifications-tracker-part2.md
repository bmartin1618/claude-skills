## State Modification Quick Reference Card

### OHIO Quick Adjustments
```
Box 1: + (Bonus Dep × 5/6) + (179 over $25k) - (Prior addbacks ÷ 5)
Box 2: Generally no modification
Box 5: Check for Ohio municipal interest
Box 11: + Federal deductions from non-CAT income
Box 14: - Business income deduction (max $250k)
```

### INDIANA Quick Adjustments
```
Box 1: + Full bonus dep (year 1) - Recovery + State tax deducted
Box 2: Check throwback impact on apportionment
Box 5: No modification unless foreign source
Box 6: Foreign dividends 100% deductible
Box 8-9: Follow federal unless timing differences
```

### KENTUCKY Quick Adjustments
```
Box 1: + State tax deducted - Pension exclusion (max $31,110)
Box 2: Generally follows federal
Box 5: + Other state muni - KY muni
Box 11: Check for Kentucky-specific items
Remember: LLET separate calculation
```

## Error Prevention Matrices

### Common State Modification Errors

| Error | Impact | Prevention | Fix |
|-------|--------|------------|-----|
| Forgot Ohio bonus add-back | Understated income by 83% of bonus | Use checklist | Amend with modification |
| Missed Indiana throwback | Understated apportionment | Review all sales | Recalculate factor |
| Wrong Kentucky LLET method | Overpaid tax | Calculate both methods | Amend for refund |
| Used federal basis for state | Wrong loss limitation | Separate tracking | Recalculate limits |
| Missed PTE election | Lost SALT benefit | Calendar reminders | Consider next year |

## State Audit Risk Areas

### High Risk Modifications
1. **Large depreciation adjustments**
   - Maintain detailed schedules
   - Document asset placement

2. **Apportionment factor changes**
   - Support sales sourcing
   - Document throwback analysis

3. **Related party transactions**
   - Show business purpose
   - Document arm's length pricing

4. **Composite return positions**
   - Verify all qualify
   - Track withholding credits

5. **PTE tax elections**
   - File timely
   - Include all required members
