# Staff Training Program - Tax Return Review

## Training Overview

### Program Structure
- **Level 1**: Basic Review (0-2 years experience)
- **Level 2**: Intermediate Review (2-5 years experience)  
- **Level 3**: Advanced Review (5+ years experience)
- **Specialized Tracks**: Partnership, Multi-State, Complex Individual

### Learning Objectives
Upon completion, staff will be able to:
1. Identify common errors in tax returns
2. Apply systematic review procedures
3. Document review findings properly
4. Recognize planning opportunities
5. Communicate effectively with clients

### Common Error Quick Reference

#### Income Errors
1. Missing K-1 items
2. Wrong character (ordinary vs. capital)
3. Incorrect basis in property sold
4. Wash sale adjustments missed
5. Constructive dividends overlooked

#### Deduction Errors
1. Personal expenses claimed
2. Hobby loss rules violated  
3. Related party transactions
4. Excessive compensation
5. Undocumented charitable contributions

#### Credit Errors
1. Dependent qualifications
2. Education credit double benefits
3. Passive activity credits limited
4. Foreign tax credit limitations
5. Carryforward tracking

#### State Errors
1. Wrong apportionment method
2. Nexus not identified
3. Throwback sales missed
4. Credits not claimed
5. Local taxes overlooked

### Review Documentation Standards

#### Required Documentation
1. **Review Notes**: Clear, concise findings
2. **Follow-up Items**: Questions for preparer
3. **Risk Assessment**: High-risk areas identified
4. **Planning Ideas**: Opportunities noted
5. **Time Tracking**: Actual vs. budget

#### Sample Review Note
```
REVIEW NOTE - 3/15/2024
Return: ABC Partnership 2023
Reviewer: [Initial]

FINDINGS:
1. Capital accounts don't tie to Schedule L 
   - Difference: $45,000
   - Likely missing distribution
   
2. Guaranteed payment not deducted
   - Amount: $120,000
   - Affects ordinary income allocation

3. State apportionment incorrect
   - OH sales should be $2.3M not $1.8M
   - Throwback rules not applied

ACTION REQUIRED:
- Verify distribution amount with client
- Add guaranteed payment deduction
- Recalculate OH apportionment

Planning Note: Consider 754 election for upcoming partner buyout
Time: 65 minutes (budgeted 60)
```

## Performance Evaluation

### Review Quality Metrics

#### Accuracy Score (40%)
- Errors caught / Total errors
- Target: 95%+ for Level 3, 85%+ for Level 2, 75%+ for Level 1

#### Efficiency Score (30%)
- Actual time / Budgeted time
- Target: Within 110% of budget

#### Documentation Score (20%)
- Complete review notes
- Clear communication
- Proper workpaper references

#### Value-Add Score (10%)
- Planning opportunities identified
- Process improvements suggested
- Client value delivered

## Best Practices for Reviewers

### Time Management
1. Review highest risk areas first
2. Use software diagnostics efficiently
3. Batch similar returns
4. Set time limits per return
5. Don't perfect what's already good

### Communication
1. Be specific in review notes
2. Provide solutions, not just problems
3. Prioritize findings by importance
4. Use consistent terminology
5. Follow up on open items

### Professional Development
1. Read daily tax updates
2. Attend monthly training sessions
3. Complete annual CPE requirements
4. Participate in peer reviews
5. Seek feedback regularly

### Technology Utilization
1. Master keyboard shortcuts
2. Use comparison tools
3. Create personal checklists
4. Build Excel templates
5. Leverage AI tools appropriately

## Appendix: Training Scenarios

### Scenario 1: The Overlooked K-1
**Setup**: Client received K-1 three weeks after initial return preparation
**Issues**: Passive loss, basis limitation, state filing requirements
**Learning Points**: Always verify all K-1s received, track basis, check state nexus

### Scenario 2: The Reasonable Comp Trap
**Setup**: S Corp with $500k profit, $30k officer salary
**Issues**: IRS challenge risk, employment tax underpayment
**Learning Points**: Document compensation analysis, compare to industry standards

### Scenario 3: The Multi-State Mess
**Setup**: Partnership operating in 8 states, inconsistent apportionment
**Issues**: Nexus overlooked, throwback missed, credits unclaimed
**Learning Points**: Create nexus checklist, understand each state's rules

### Scenario 4: The Basis Disaster
**Setup**: Partner taking losses exceeding basis for 3 years
**Issues**: Suspended losses, at-risk limitations, debt basis
**Learning Points**: Maintain detailed basis schedules, understand limitation ordering

### Scenario 5: The AMT Surprise
**Setup**: Executive exercised ISOs, large state tax refund
**Issues**: AMT triggered, credit carryforward, planning opportunities
**Learning Points**: Run AMT calculation early, plan ISO exercises, time deductions
