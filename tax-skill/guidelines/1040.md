# Form 1040 Review Checklist

## Initial Data Verification
- [ ] **Taxpayer Information** - Name, SSN, address match prior year
- [ ] **Filing Status** - Appropriate for facts (MFJ/MFS/HOH/Single analysis)
- [ ] **Dependents** - All qualifying tests met, SSNs valid
- [ ] **Prior Year Items** - Carryforwards properly applied
- [ ] **Information Returns** - All W-2s, 1099s accounted for and matched

## Income Verification

### Wages & Employment (Line 1)
- [ ] W-2 Box 1 matches return
- [ ] W-2 Boxes 3 & 5 reconciled for state returns
- [ ] Retirement contributions verified (Box 12)
- [ ] State wages reconciled to federal

### Interest & Dividends (Lines 2-3)
- [ ] Schedule B filed if over $1,500
- [ ] Qualified dividends properly separated
- [ ] Tax-exempt interest reported but excluded
- [ ] Foreign accounts disclosed if required (FBAR/8938)

### Business Income (Schedule C)
- [ ] Business code accurate and consistent
- [ ] Accounting method consistent year-over-year
- [ ] Home office deduction calculated correctly
- [ ] Self-employment tax on Schedule SE
- [ ] Vehicle expenses substantiated
- [ ] Gross profit margin reasonable for industry

### Capital Gains (Schedule D)
- [ ] Basis calculations verified
- [ ] Wash sale rules applied
- [ ] Capital loss carryforward utilized ($3,000 limit)
- [ ] NIIT considered if MAGI exceeds threshold
- [ ] Cryptocurrency transactions included

### K-1 Income (Schedule E)
- [ ] **Partnership/S Corp** - All K-1 items properly placed
  - Box 1 ordinary → Schedule E Part II
  - Box 5 interest → Schedule B
  - Box 9a capital gains → Schedule D
  - Box 11 other income → appropriate line
  - Box 13 credits/deductions → various locations
  - Box 20 state items → state modifications
- [ ] **Basis Limitations** - Applied per K-1 instructions
- [ ] **At-Risk Limitations** - Checked and documented
- [ ] **Passive Activity Losses** - Properly suspended or utilized
- [ ] **Self-Rental Rules** - Applied if renting to own business

### Rental Income (Schedule E Part I)
- [ ] Active participation for loss allowance ($25k phaseout)
- [ ] Real estate professional status if claiming
- [ ] Depreciation recapture on dispositions
- [ ] Passive activity designation correct

## Deduction Review

### Standard vs Itemized
- [ ] Both calculations performed and compared
- [ ] State tax benefit considered for itemizing

### Schedule A - Itemized Deductions
- [ ] **SALT** - Limited to $10,000 (state income + property)
- [ ] **Mortgage Interest** - Acquisition debt limits applied
- [ ] **Charitable Contributions** - Substantiation requirements met
  - Cash donations: Bank record or receipt
  - >$250: Written acknowledgment
  - >$500: Form 8283 for non-cash
  - Percentage limits applied (30%, 60%)
- [ ] **Medical Expenses** - Exceed 7.5% AGI floor
- [ ] **Casualty Losses** - Disaster area only (post-TCJA)

### Above-the-Line Deductions
- [ ] **IRA Contributions** - Within limits, phase-outs applied
- [ ] **HSA Contributions** - HDHP coverage verified, limits checked
- [ ] **Student Loan Interest** - $2,500 limit, phase-out applied
- [ ] **Self-Employed Health Insurance** - Cannot exceed profit
- [ ] **QBI Deduction** - Form 8995/8995-A completed correctly

## Credit Review
- [ ] **Child Tax Credit** - Qualifying child tests, SSN requirements
- [ ] **Additional Child Tax Credit** - Refundable portion calculated
- [ ] **Earned Income Credit** - Diagnostic run, due diligence met
- [ ] **Education Credits** - AOTC vs Lifetime Learning optimized
- [ ] **Retirement Savings Credit** - AGI limits checked
- [ ] **Foreign Tax Credit** - Compared to deduction alternative
- [ ] **Residential Energy Credit** - Documentation on file
- [ ] **Premium Tax Credit** - Form 8962 reconciliation

## Tax Calculation & Payments

### Special Taxes
- [ ] **Alternative Minimum Tax** - Form 6251 if income >$200k or large SALT
- [ ] **Net Investment Income Tax** - 3.8% if MAGI exceeds threshold
  - Single: $200k, MFJ: $250k
  - Investment income properly identified
- [ ] **Additional Medicare Tax** - 0.9% on wages/SE income over threshold
- [ ] **Kiddie Tax** - Applied if dependent with unearned income >$2,500

### Estimated Taxes & Penalties
- [ ] **Withholding** - W-2 and 1099 withholding verified
- [ ] **Estimated Payments** - Applied with dates
- [ ] **Prior Year Overpayment** - Applied if elected
- [ ] **Underpayment Penalty** - Calculated or safe harbor documented
  - 90% of current year tax
  - 100% of prior year (110% if AGI >$150k)
  - Annualized income exception

## State Return Coordination
- [ ] Federal AGI flows correctly to state
- [ ] State additions/subtractions calculated
- [ ] Multi-state apportionment if applicable
- [ ] State-specific credits claimed
- [ ] Local/city returns filed if required

## High-Risk Review Areas

### Audit Triggers
- [ ] Cash-intensive business (Schedule C)
- [ ] Home office deduction (reasonable %)
- [ ] Vehicle business use (100% claims)
- [ ] Large charitable contributions (>20% AGI)
- [ ] Hobby loss rules (3 of 5 year profit test)
- [ ] Foreign accounts/transactions

### Common Errors
- [ ] K-1 items misplaced on return
- [ ] Passive losses claimed without documentation
- [ ] AMT not calculated when required
- [ ] NIIT missed on high-income returns
- [ ] Basis limitations not applied
- [ ] State tax refund not included in income (if itemized prior year)
- [ ] Estimated tax penalty not calculated
- [ ] Capital loss carryforward not applied

## Quality Control
- [ ] All arithmetic verified
- [ ] Year-over-year comparison reviewed
- [ ] Effective tax rate reasonable
- [ ] Software diagnostics cleared or documented
- [ ] All required signatures obtained
- [ ] Extension payment applied if made

## Planning Opportunities Identified
- [ ] Retirement contribution strategies
- [ ] Timing of income/deductions
- [ ] Estimated tax payments for next year
- [ ] State tax planning (residency, entity structure)
- [ ] Education savings/credit optimization
- [ ] Capital loss harvesting opportunities
- [ ] QBI deduction maximization strategies
